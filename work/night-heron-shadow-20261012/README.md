# 夜鹭的一天 · 皮影动画交接包

先打开 **素材预览.html** 查看10张透明PNG及各姿态。将整个文件夹交给DeepSeek，入口指令见 **DeepSeek接手说明.md**；完整分镜和动作设计见 **制作计划.md**。

本包包括：6张动作图集（26个姿态）、1张夜鹭设定、鱼/桶/巢3个道具；50秒竖屏计划；600个动作节拍、1200条输出帧状态。每帧指定角色姿态，鱼的归属和遮挡状态；保持与复用已展开，不是1200幅独立原画。

素材是已生成的RGBA PNG，角色伪装保留原夜鹭身份，结尾回巢喂幼鸟。正式版本以asset-manifest.json为准，history为历史。

这些姿态尚须在动画制作时完成身体配准、支撑脚锁定和嘴鱼接触校准。检查已覆盖文件/alpha/裁切边缘/引用/时间线，未覆盖实际视频流畅性与音频。本轮按用户要求交付计划和素材，没有生成成片或自动调用DeepSeek。
