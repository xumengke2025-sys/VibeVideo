# 夜鹭的一天 · 待审制作说明

delivery_mode: ai_review_once。50秒，1080×1920，24fps，1200帧。原图复用为刚性皮件；每帧按绝对时间计算躯干、头、上下颈片、膝腿、脚、下颌、翻面角和鱼锚点，不用整图弹性变形模拟动作。

| 时间 | 建立、变化、结果 |
|---|---|
| 0–5 | 清晨出发，夜鹭身份建立 |
| 5–10 | 穿过动物园门 |
| 10–15 | 看见企鹅与鱼桶，翻面观察四周 |
| 15–21 | 躯干立起、缩颈、脚靠拢，模仿企鹅小步摆动 |
| 21–27 | 停步翻面回看，再转回鱼桶 |
| 27–32 | 伸颈、开嘴、夹鱼、收颈；第680帧鱼从桶归夜鹭 |
| 32–36 | 企鹅转头，夜鹭停住后翻面离开 |
| 36–41 | 携鱼向左返家 |
| 41–46 | 两只幼鸟伸颈，鱼从第1048帧开始送入巢前缘后方 |
| 46–50 | 夜鹭收颈，幼鸟安静，家庭结尾 |

用户最新约束：夜鹭与企鹅大小接近；伪装段体态直立像企鹅，保留黑帽、红眼、长嘴和白色后颈羽；要有偷偷观察、停顿、碎步的偷感。动物园企鹅池后有假山。树、假山与地条为有纹样、镂空和皮革疏密的景片。所有角色动作参照关节皮影，翻面保持同一皮件。

声音是本项目原创合成：木步、轻锣、水声、幼鸟声和稀疏拨弦，无旁白。仅技术检测或事件表不能作为听过声音的证据。

参考：本地lemomo-ai/lemo-opuscar/styles/shadow-puppet，实际读STYLE.md、stage.js、scenery.js、carve.js、gl.js、houyi.js和main.js的关节/动作段；实际看styleframe.jpg及styleboard图。采用原MIT透射合成、刻皮与景片模块，许可在vendor/LICENSE，调整与来源在vendor/NOTICE.md。没有声称完整观看上游视频。参考mir是幕前/幕后镜像；本片在此基础上自行增加刚性皮片绕竖轴的余弦侧缘投影翻面。

每镜以固定舞台呈现皮影动作；景别主要为完整舞台，接触动作保持可见。保留24fps逐帧寻址。早期12fps原素材计划作为历史资料，不等于当前视频的逐帧实现。
