# 《夜鹭的一天》制作计划
本轮交付：透明角色/道具、逐帧动作结构、DeepSeek 制作交接。成片由后续制作完成；本包没有 MP4，不宣称已验证动作连贯性。
画幅 1080×1920，竖屏；时长 50 秒；输出 24fps。角色姿态按 12 个动作节拍/秒设计，一个节拍保持两个输出帧。需要更细的运动时，增加关节中间姿态，不能用溶解补帧。
delivery_mode 尚未选择：当前是素材与计划准备。开始正式视频制作时，按项目规则只问一次“①直接生成，你反馈后修改；②AI 审核一轮，再交付”。

## 故事与美术
一只夜鹭晨间出门，路过动物园，发现企鹅的鱼桶。它缩颈、并脚、学企鹅短步，悄悄挪到桶旁。探颈叼鱼的一瞬长嘴露馅，企鹅回头。夜鹭叼着鱼快步离开，傍晚把鱼交进巢里，两只小夜鹭探头围食。
这是拟人寓言，不把“有意伪装企鹅”或片中的喂食方式写成已证实的夜鹭行为。
采用彩色皮影的平面侧身、镂刻牛皮质感、暖色透光、刚性关节和节拍式表演。背景由代码制作暖米色幕布、水平地台、动物园门牌及简化池岸；复杂角色与道具使用已生成的 PNG。舞台文字“动物园”“企鹅”用实际字体排版。
夜鹭原型：黑冠、红眼、长尖嘴、两根白色枕羽、灰黑翼与米白腹。伪装靠姿态和走法，不换脸、不换短嘴、不长企鹅鳍。幼鸟采用棕褐色斑点羽衣。企鹅始终使用 penguin_react 一套，早期独立企鹅设定不纳入本包，避免切换造型。

## 方案取舍
考虑了“披企鹅服混入”“直接冲桶抢鱼”“模仿企鹅排队”三种机制。选第三种：既保留夜鹭身份，又能让侧身皮影的嘴长、腿形差异成为笑点，且不需要额外衣物穿脱、飞行或追逐资产。

## 竖屏分镜
| 时间 | 观众新理解 | 主动作与结果 | 镜头、构图与声音 |
|---|---|---|---|
| 0–5秒 | 主角是夜鹭，晨间出门 | 低头停驻→抬颈→迈步离场 | 中景；主体下中部，上半留晨光与片名；轻鸟声、木板轻点 |
| 5–10秒 | 来到动物园 | 同方向步行穿过门牌下方 | 侧向舞台；门牌上方、夜鹭下方；两次明确脚步声 |
| 10–15秒 | 它盯上企鹅的鱼桶 | 立定→半探颈→收回 | 拉近的独立机位；夜鹭左下、企鹅右中、桶右下；桶鱼先可见，后给夜鹭反应 |
| 15–21秒 | 它在学企鹅 | 收颈→并脚→四拍短步 | 固定机位；与企鹅同一落脚线作比较；短木鱼节奏 |
| 21–27秒 | 它挪到桶旁 | 两轮短步→站定等待 | 近中景；完整保留嘴与桶的位置关系，最后停一拍 |
| 27–32秒 | 抢鱼的关键过程 | 半伸→长伸→张嘴→接触→合嘴→提起 | 接触近景，镜头锁定；鱼桶前沿遮住嘴尖进入的一段；合嘴时一点清脆木响 |
| 32–36秒 | 伪装露馅 | 主角叼鱼僵住；企鹅依次转头抬翅 | 回到双角色中景；先看鱼，再看企鹅；小锣后留空拍 |
| 36–41秒 | 鱼被带走 | 用步行组加快节拍叼鱼离场 | 同方向经过路径；无需飞行，不能拿静图平移冒充飞行 |
| 41–46秒 | 抢鱼是为了幼鸟 | 成鸟探颈→幼鸟张嘴→把鱼交入巢 | 成鸟左、巢与幼鸟右；真实接触后鱼进入巢前沿遮挡；幼鸟错拍鸣叫 |
| 46–50秒 | 一家安定下来 | 幼鸟低头围食→收口→成鸟收颈停住 | 稍宽一镜；傍晚幕光，最后停1秒；短尾音，不增加新动作 |

切镜遵循：夜鹭一直向右行进；S03→S04保留角色队列；S05→S06在双脚站定时切近景；S06→S07保持鱼已被夹住；S08→S09用同一条鱼完成动机揭示；S09→S10在鱼进入巢、成鸟嘴部释放后切宽。
返回用傍晚低光说明时间经过，不安排没有动作素材的腾飞、着陆、翻身或扑翼。

## 所有动作的逐帧结构
帧号 .0 起算，图集按上排从左至右再下排排列；真正裁切范围以 asset-manifest.json 为准。
下表括号是12fps动作节拍数，每个节拍对应2个24fps输出帧。完整展开在 frame-plan-1200.json；不是1200张不同绘画。
| 动作 | 逐帧关键姿态与保持 | 支点与衔接 |
|---|---|---|
| 停驻/抬头 | neck.0(12) → .1(8) → .0(4) | 两脚锁定；躯干不呼吸缩放 |
| 观察鱼桶 | neck.1(8) → .2(4) → .1(12) | 嘴指向鱼桶，躯干留原处 |
| 普通步行/叼鱼回家 | walk.0(2) → .1(1) → .2(2) → .3(2) → .4(1) → .5(2) | 落脚、承重、通过、另一脚落地；叼鱼时只多鱼的嘴部绑定 |
| 装企鹅准备 | neck.1(6) → .0(6) → disguise.0(12) | 羽色和长嘴保留；先收颈后并脚 |
| 企鹅式短步 | disguise.0(3) → .1(2) → .2(3) → .3(2) → .0(2) | 小步、短停，靠关节，不横向压扁身体 |
| 桶旁等待 | disguise.0保持 | 给观众看清桶、嘴、企鹅三者位置 |
| 探桶抢鱼 | neck.1(4) → .2(3) → .3(3) → contact.0(3) → .1(3) → .2(4) → neck.3(3) → .2(3) → .1(10) | .1张嘴；contact.2合嘴时捕获；鱼随后跟嘴离桶 |
| 露馅僵住 | neck.1(12) → .2(4) → .1(8) | 保持叼鱼；不再生成第二条鱼 |
| 企鹅察觉/回头/抗议 | penguin.0(4) → .1(4) → .2(10) → .3(6) → .2(8) → .1(4) → .0(12) | 身体、双脚不转；主要动头和鳍；第二只延迟8节拍 |
| 回巢喂食 | neck.1(4) → .2(4) → contact.3(4) → .1(4) → .2(4) → .1(4) → neck.2(4) → .1(8) | 接触在松嘴前；鱼归属由成鸟改为巢 |
| 幼鸟等待/探头/张嘴 | chick.0 → .1 → .2 | 完整绝对时点在时间线；第二只延迟3节拍，大小固定差异 |
| 幼鸟围食/收口 | chick.2 → .3 → .0 | 鱼进入巢前沿后两只错拍低头；不演完整鱼被两只重复吞下 |
| 收尾停驻 | neck.1(12) → .0(12)；chick.3 → .0 | 留停顿，不加弹簧缩放 |

## 皮影运动约束
1. 头、上下嘴、颈段、翅、腿是刚性片，围绕关节转动；连续帧之间禁用整图非等比拉伸、液态变形、AI补帧溶解。
2. 步态的支撑脚落地期间，脚尖世界坐标固定。先对齐身体和关节，再用支撑脚反推 root 位置；时间线里的 root 是构图建议，不能原样线性平移导致滑步。
3. 每个动作先摆“预备”，再出“主动作”，在嘴碰鱼、脚落地、企鹅回头处停2–4帧，最后回收。皮影的停顿是表演，不等于缺中间态。
4. 不能把不同图格按外接框各自缩放到同样高度；长颈帧应更高/更长，躯干尺寸保持一致。pose-anchors.json给出初始躯干尺度与部分锚点估计，必须在叠加标记下校准。
5. 切换动作组时，对齐肩关节、髋关节和支撑脚。若羽纹闪动，在动画渲染层复用同一躯干/翅片，只切换对应头颈或腿部姿态；不可用淡入淡出藏闪动。
6. 层序：幕布→场景→远侧角色→桶后部/巢后部→活动嘴/鱼/幼鸟→桶前沿/巢前沿→必要近侧下嘴。前沿遮挡用同一原图的clip区域，不用粗矩形盖住整个动作。
7. 鱼只有一个hero_fish身份。第340动作节拍（28.333秒、输出帧680）从桶转到嘴；第524节拍（43.667秒、输出帧1048）从嘴转到巢。变更归属前后世界坐标必须连续。
8. 摄影机以锁定侧机位和切景别为主。景别改变是一镜之内整场景一致缩放，不能只放大某只角色。

## 声音计划
以动作驱动声音，不铺满拟音。步行落脚轻板音；缩颈短顿用木鱼；合嘴一点木响；露馅小锣后留空拍；回巢幼鸟两次错拍鸣声；结尾温和收音。当前未生成音频，后续只能使用已有授权素材或原创合成声音。不会把音频计划说成已配音。

## 真实完成范围
已完成10张正式透明PNG，6张角色动作图集共26姿态，加1张角色设定及3个道具；50秒分镜、15类动作定义、600动作节拍、1200输出帧记录。文件解码/透明通道、素材引用、时长覆盖和鱼的逻辑归属已检查。
图集由生成模型产生，不是同一套骨骼渲染。步行前后半程较相似、跨动作组体态及纹样仍有差异；锚点是初值，不是成片验收。后续须落实支撑脚、嘴鱼接触、身体片复用与必要的关节中间态，才能称为动作顺畅。此包不以“生成了多张姿态”代替实际连播验证。
