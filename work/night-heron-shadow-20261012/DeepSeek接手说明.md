# 给 DeepSeek 的制作任务

请基于本目录完成《夜鹭的一天》50秒彩色皮影动画，1080×1920竖屏，24fps。先读制作计划.md、asset-manifest.json、action-library.json与shot-plan.json，再读取逐帧清单。不要把本目录当成已经完成或验收的视频。

本次用户交给前一角色的是“计划＋透明素材”，未选择视频交付模式。开始正式视频项目前只问一次：“这次选哪种方式：①直接生成，你反馈后修改；②AI 审核一轮，再交付？”把回答记录为delivery_mode=user_feedback或ai_review_once；按当前项目AGENTS.md执行，不另开强制导演或双模型流程。

## 必须保留的创意

- 夜鹭混进动物园，缩颈并脚假扮企鹅，伸长脖子从企鹅鱼桶抢鱼。
- 伪装前后是同一只夜鹭：黑冠、红眼、长尖嘴、两根白枕羽和同一羽纹，不变成另一只企鹅。
- 最后带鱼回家，把鱼交进巢给两只小夜鹭围食。
- 所有角色动作都要有逐帧结构；不能靠整张角色图弹跳、平移、拉伸或交叉溶解代替动作。
- 皮影特点体现在关节旋转、侧身表演、脚下支点和动作停顿，不只是皮影纹理。

## 先把姿态变成可靠的角色动作

1. 原图只读保留；运行时按sourceRect读取。各图不一定严格等分，尤其幼鸟上、下行高度不同。
2. 建立统一角色局部坐标：肩、髋、左右脚尖、嘴铰链、夹鱼点。先在正式竖屏构图叠加标记，校准pose-anchors初值；没有标记的walk/disguise/chick/penguin也要逐格标记。
3. 保持一只角色的躯干长度和羽纹固定。生成图格仍有形体/纹样漂移，因此跨图组优先复用一个躯干和翅片，在渲染层遮罩组合对应头颈、腿部；不要把整格按不同外框各自缩放到相同高度。
4. 步行表的两排相位较相似，不能把6格直接当作严格左右腿循环。按支撑脚纠正近侧腿/远侧腿遮挡；必要时从已有腿片做刚性关节中间态，保存为明确的逐帧pose配置。禁止重新生成整个角色导致身份漂移。
5. 把每个动作片段做成可寻址帧函数，禁止依赖墙上时钟、随机帧或实时弹簧积分。每个frame输入都应得到相同姿态。
6. 时间线root只是舞台布局初稿；行走时用落地脚尖的世界坐标反求角色root，解决滑步。原图中脚的局部位置不能忽略。
7. 中间帧只通过皮影部件绕关节转动或新增同角色姿态实现，不用整图形变或溶解。镜头切换可以遮住换机位，但不能遮掉必要的抓鱼/交鱼接触过程。

## 接触与遮挡必须按帧求解

- 鱼：长度约成鸟嘴长的0.9–1.2倍，固定一条hero_fish。桶内可以复用鱼素材作为静态其他鱼，但被抓走的身份只能有一个。
- 桶：近景放在主角右下，让合嘴帧的夹鱼点落在桶口里。桶是单张素材，用原图clip建立后部和前沿两个渲染层；鱼先被前沿遮住，下探的嘴尖也应进入遮挡区。
- 抢鱼：poseTick340 / outputFrame680为鱼从桶转为嘴子节点的一帧。先保留鱼的世界矩阵，再转成本地矩阵，不能在这帧跳位置；夹鱼点对齐上、下嘴之间，鱼不能一直粘在嘴外尖端。
- 提鱼：鱼跟随嘴的每一帧姿态，刚性小幅转动。只允许一次可读摆动，不能用弹簧无限抖。
- 巢：成鸟在左，两只幼鸟在右，幼鸟腿部位于巢前沿后。利用nest原图clip建立前沿，不裁掉幼鸟头部。
- 交鱼：poseTick524 / outputFrame1048从成鸟嘴转入巢。接触发生在释放之前；poseTick528以后鱼被巢前沿遮住，530以后不再显示。幼鸟们错拍低头围食，不能演完整鱼给第一只后又凭空重新喂第二只。
- 所有鱼的归属变化都要保持世界位置连续，并在前后至少4个输出帧逐帧检查。

## 场景与镜头

舞台用暖米色透光幕布、深赭/藏蓝远景、明确水平落脚线。用代码绘制静态动物园门牌、池岸、路径，不需要再调用生图。门牌写“动物园”；桶旁可用小牌“企鹅”，文字由字体渲染。幼鸟和巢是真正PNG素材。

保持镜内固定侧机位，镜间改变景别。桶接触近景需要按嘴和桶重排root，不能把时间线的建议坐标当作最终接触坐标。不要增加未规划的飞行、追逐、转身180度、开翅或跳落树枝。

## 最小制作顺序

先完成“桶旁站定→伸颈→张嘴→合嘴夹鱼→提出桶口”约5秒样段，验证角色身份、支点、遮挡和鱼绑定；然后接伪装步态、企鹅反应、回巢喂食与前后场景。样段是内部制作，不另派审片者。

交付实际MP4前至少检查文件解码、1080×1920、50秒、24fps、预期音轨、开头结尾和关键接触帧。若用户选直接生成则展示由用户反馈；若选AI审核一轮则遵循项目的一轮流程。不要声称本素材包已经验证过声音、步行循环或全片流畅性。

可重建JSON：node generate-frame-plan.mjs。可重建素材检查页：node build-preview.mjs。Windows RGBA检查：powershell -File verify-assets.ps1。生成脚本不导出影片，也不改写PNG。
