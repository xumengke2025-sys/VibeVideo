# 把导演意图变成可执行镜头

用于完整原创片与现有片的导演改造。先写观众路径，再选几何、图片或引擎。没有必要为简单片子填写庞大表格。

## 整片先有一条线

### 编码前的创意选择

先留下一个简短 creative-direction 记录。回答：前几秒看什么；最值得记住的画面；好奇从何而来；什么变化推动观看；意外与主题的内在联系；结尾比开头多了什么含义；去掉材质和特效后构图/动作是否仍成立。

默认列三个不同事件逻辑的候选，各含一句话概念、关键视觉事件、观众体验、核心镜头、最难实现处、技术可行性/成本、适配理由。不是同一情节换色或换角度。业务目标明确时自主选择，记录淘汰理由；纯工具动作允许压缩为一段。没有意外也可以成立，不能强加剧情反转。

探索方法：因果变化、语义变形、尺度揭示、视角发现、2D/3D空间转换、第二次行为改变理解、视觉押韵、延迟解释、动作接力。每次只选有助理解或情绪的方法，列出不使用什么及原因。运动是否改变关系，比运动对象数量更重要。

|类型|创作目标|可考虑的方法|事实/表达边界|
|---|---|---|---|
|产品|价值与使用感受|操作引发结果、材质/尺度对照|不虚构功能|
|科学科普|理解与发现|先现象后机制、同一对象换尺度|揭示不能改事实|
|机械|结构、受力和反馈|接触近景、约束行程、载荷改变状态|轴线/接触/弹簧固定端正确，勿套角色弹性|
|抽象图形|形式与节奏|点对应变形、动作接力、形状押韵|中间态有设计，不必虚构故事|
|角色|意图、判断、情绪|预备/反应/跟随/恢复|夸张服务表演|
|数据|关系与信息揭示|稳定轴/单位、同一数据重组|不改尺度制造反转|
|3D空间|空间、尺度和环境关系|遮挡揭示、主体与环境相互影响|不以持续绕圈充数|

### 动态预演的门槛

复杂片先用已有引擎与简化几何、低分辨率/较低fps，导出完整动作段，保留时间码与状态。预演生成后按 independent-av-review.md 由第二角色逐帧审核并检查音频，依据预演目标检查主体、因果、注意交接、有无重复与完成感，有限修复和复核后展示可播放版本；用户明确要求先看时直接展示并标明审核状态。镜头可以停机、全片可以一镜；时间按阅读/蓄势/变化/释放需求分配，不强制平均或固定三段。预演输出与正式分辨率分别记录。

用几句说清：观众是谁；开场让他期待什么；哪个变化会兑现这个期待；前面的信息怎样让这一刻容易理解；最后留下什么。给递进、高潮和安静分配时间，不按“六个知识点”自动分成六张同布局页面。

视觉母题是反复被赋予新含义的对象。点可以从图表游标变成地形上的位置，线可以从传播路径变成结构轮廓。色彩/材质保持功能，构图和动作可以变化。不要把 pdoom 的橙线、纸底、怪物或逐词字幕当成跨题材模板。

## 把一镜写成可执行关系

|字段|决策用途|
|---|---|
|新理解/感受|这一镜为什么存在；若与上一镜相同，考虑合并|
|建立→变化→结果|起点需可见，接触/变化需正确，结果需有足够阅读停留|
|主体动作|对象、起止时间、轨迹/状态、中间态、接触事件；没有动作时说明停留的意义|
|相机|景别、机位、视角/焦距、look-at、运动轴线、速度与停机；说明这次移动揭示什么|
|注意与文字|先看谁，再看谁；标注跟世界坐标还是屏幕；何时出现与撤走|
|理解顺序 reads|观众依次需认出什么、理解什么变化与结果；出现、可辨认、离开时刻分别记录，文字完整出现后保留阅读时间|
|声音|真实词重音/拍点，或原创事件；接触音按接触时刻，理解结果时可减音|
|资产|平面素材可支持的裁切/小运动；大转向、背面、遮挡需要几何、多视图或视频|
|连接|前后共享锚点、切的理由、切点状态、风险窗口；剪切不必假装连续变形|

镜头同时发生大量动作时，先区分主因果与注意引导。相机与标签不必陪主体一起忙：重要接触处停机，事件完成后才换位或拉远。用前景遮挡与视差证明空间，而不只转动一个平面素材。

## 连接要有可检查的对象

- 形状/位置匹配：给前后锚点的屏幕位置、轮廓和方向；看剪前末帧及剪后首帧。只有共同颜色时，称色彩/语义剪辑，不称几何对应。
- 动作匹配：记录速度和轴线；需要连续时保证位置连续，必要时检验速度。切过轴线要重新建立空间关系。
- 遮挡切：遮挡来自场景内对象，先让遮挡动机可读；不要用闪光覆盖每个断点。
- 连续变形：说明对应哪些顶点/路径/字形、如何过渡、中间态是否仍有含义。没有对应关系时，明确切换通常更诚实、更清楚。
- 声音桥：音的进入/离开跨过切点，以叙事作用选时长，避免每镜都重击。

## 实际用过的镜头例子

原创“蓝色的建筑”用生成的蝶翼与鳞片概念图建立宏观/微观层级，以同向脊线剪至三维层架；相机降低让层间空隙从遮挡中显露；接着明确切到静止剖面，由光的动作完成两次接触；两路反射再变为波形对比，最后拉远回收许多脊线和整片蓝色。图像没有被旋转来假装真实三维，三维结构与波形也没有冒充精确生物/电磁仿真。

一个机制镜头的计划可以这样写，而不是“加入光效和高级运镜”：

```json
{
  "id": "two-paths", "start": 22, "end": 32,
  "intent": "同一束光在两层反射，形成不同路程",
  "states": {"establish": 22.8, "action": 25.5, "result": 30.0},
  "action": "24.4秒上层接触；25.5秒下层接触；两路出射均可见",
  "camera": "固定斜侧剖面；让光移动，相机停止",
  "sound": "两次接触的同音短声；结果后减音",
  "risks": [[24.2, 24.7], [25.3, 25.8]]
}
```

`scripts/shot_contract.py` 的完整输入为 `{duration,fps,shots:[...],connections:[{time,kind,anchor,window:[a,b]}]}`。它核对镜头时间覆盖、三个状态的先后、风险窗及连接，输出代表帧与连续帧区间。有审阅日志时可传 `--video final.mp4 --review review.json`，核对哈希和逐镜头状态覆盖；日志必须来自实际观察，不能由脚本自动填“看过”。

## 正面诊断旧片

先看整片布局与情绪，再看关键动作。把问题写为“时间/可见现象→影响理解→具体改法→验证状态”。例如：90秒旧片52–54秒用左右擦拭把二维图换成三维；正确改法不是重命名为变形，而是选择同一个弧线/对象匹配，或明确切镜并重新建立空间。32秒旧片确有高低机位变化，但光点在宽景中太小；应先近景读接触，随后拉远读结果。技术解码通过不回答这些问题。

先改最影响观看的一项并做完整动作片段。修好之后扩展全片；把失败与修正写入验证记录，区分本次有效方法和候选路线。人物大角度动作、复杂字符连续变形、真实快门采样等没有在原创验证片中跑过，就继续标为按题材验证。
