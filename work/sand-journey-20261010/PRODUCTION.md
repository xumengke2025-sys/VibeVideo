# 一粒沙，看见整片海

观看承诺：从可辨认的一粒有棱角的沙出发，真正穿过暖沙与冷海的三维环境，越过小沙脊见到海，再归入海岸。

故事已经由用户指定。采用连续世界跟拍＋尺度揭示；同一粒沙的形状、ID和大小始终不变。起风是动作输入，越脊是视野变化，浪缘是环境相遇，落回沙面是结果。无旁白、字幕、标题卡或背景歌曲。

|时间|动作与观众所得|摄影任务|声音|
|---|---|---|---|
|0–4|静止的沙先滚动，随后离地；近处少量沙粒响应同一风|微距低机位，保留侧方行进空间|低风渐强，细碎摩擦|
|4–9|沿同一路径越过沙面起伏|侧后方真实跟随，沙脊形成前景遮挡|风和近处掠过声|
|9–13|越过沙脊，第一次看清海|连续升高、退开，短暂减速；关注从沙交给海|海浪由远转近，风减弱|
|13–17|沿近岸浪缘飞行，短暂进入飞沫遮挡再出现|收回近景跟拍，保持方向与形状|近浪展开，飞沫掠过|
|17–20|18.2 秒触沙，滚动后停住|接触处仍近，随后退开到整片海岸|18.2 秒落沙，收束至远海|

连接：全片无切镜，相机位置/看向点/FOV分别连续求值；尺度转换来自真实移动。地形与波浪的 CPU/GLSL 高度保持一致。主角大小固定，宽景自然缩小。
