# 数据叙事

适用：数量比较、趋势、组成、关系与变化。数据的变化或同一数据的不同表达成为主动作；图表选择由要回答的问题决定。

## 视听语法

- 印刷式纸面、清晰字形、克制的色板。中性色表示常态，强调色表示当前发现，同一含义贯穿全片。
- 坐标、单位、样本范围和来源可读；演示数据显著标明。数量比较从真实基线开始，不能为了画面好看改变数据关系。
- 标题给出问题/发现，标注指向证据。数字在同一位置可被追踪；不靠标题宣称图中没有显示的结论。
- 相机保持坐标稳定便于读数；靠近细节时保留尺度与上下文，拉远揭示整体。静止摄影经常比移动更有效。
- 声音响应数据点进入、关键发现与表达切换。节拍可以帮助排序，不压缩阅读时间。数字密集时降低音效密度。

## 核心动作菜单

路径沿真实样本生长；相同数据 id 从点延伸为柱；排序时保留对象轨迹；拆分组成时守住总量；一组坐标从局部扩展至全域；标注随同一对象变化。折线撤去与柱形生长不等于任意轮廓的几何 morph，应准确描述所实现的变化。

## 常见失败

中间态先显示最终读数但点仍在移动而造成误读；最大值高亮指错样本；切换图表时更换了基线；视觉排序与标签不一致；演示值被当作现实统计；字幕遮住轴或数据。

演示的移动阶段不允许读数时，可把数值延迟到落定再显示。需要读变化过程时，数值与实际状态一起更新；不要让数据动画暗示不存在的历史过程。

## 变体空间

可以从一个异常值追问原因，从总量拆到组成，从单个样本拉到总体。每次选择内容自己的发现，不默认“折线转柱形”适合所有数据。
