# 工程蓝图

适用：机械、结构、装配、设计迭代；使用剖切、尺寸和沿路径跟随说明因果。让设计物件成为主体，标题和标注属于图纸。

## 视听语法

- 深浅普鲁士蓝纸面，淡白轮廓；纤维与网格固定在纸面坐标。细节、轮廓、中心线使用不同线宽；近景看结构，远景保持轮廓可读。
- 中心线 → 外轮廓 → 内部 → 剖面排线 → 测量 → 标注。顺序可以按观众需要调整，不能让真实零件与标注失去对应。
- 文字作为图号、部件引线、测量和设计说明；避免固定大标题加图解。字体由语种与可用授权选择，中文需验证字形和阅读。
- 图纸上平面/斜投影为默认语言。混合真实三维时重新定义该片视觉规范并说明，不把解析投影或示意曲线称为物理模拟。
- 色彩功能：蓝为载体，白为结构，淡蓝为辅助信息。可用一次明显的印章/状态色表达结论；具体颜色和次数按内容决定。
- 拟音来自纸、绘图、部件接触和机制运行。配乐可用互相咬合的短动机；科普旁白优先可懂度，不必铺满音乐。

## 核心动作菜单

剖切线扫过后显示内部；部件沿装配轴依次分离；标注跟随部件；尺寸线测量真实运动端点；相机沿传力/流动路径移动；修订号或状态栏呈现设计变化。选择能解释本片的动作，不全部堆入一支视频。

## 摄影与失败

全图用于建立关系；靠近接触点解释因果；跟随部件保住锚点；拆解时拉开留空间；完成后停留读结果。不是必须具备固定数量的运镜。

常见问题：图纸边缘文字被放大裁切；粗线在近景膨胀；剖切前后零件位置漂移；箭头穿过关闭的通路；弹簧与阀瓣不同步；虚构尺寸被误读为设计值；排线与标注重叠。

## 变体空间

可讲一件装置由故障到修复、一张图纸从方案到结构、同一物件从外观到内部。开场、高潮、结尾和镜头路线从题材重新选择。
