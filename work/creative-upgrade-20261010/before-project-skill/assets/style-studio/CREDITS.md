- 制作方法研究：LemoLab / Lemomo 的 [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)，重点为 DIRECTOR.md、TECHNIQUE.md、Blueprint / Whiteboard / Ink Wash 文档。2026-10-09 查阅；本轮没有观看或重建其原始样片。
- 当前官方根目录 LICENSE / README 标为 MIT；第三方素材保持各自授权。文章提到的“说明书/影片 CC BY 4.0”不作为本轮授权依据。
- 本工程的 Canvas、事件契约、合成拟音与示例故事独立编写，没有复制 lemo-opuscar 的绘制源码、音乐、角色或品牌标识。
- 阀门事实参考：[Check valve](https://en.wikipedia.org/wiki/Check_valve)。本片只解释弹簧式轴向止回阀的简化动作：正向压差克服弹簧力开通，压差降低后弹簧复位。粒子、外壳和支撑结构为示意，不是实物工程图。
- 数据 `[18,28,22,47,39,64,74,62]` 为原创演示值，无现实统计含义。画面中明确标记。
- 字体使用本机 Microsoft YaHei / Bahnschrift / Consolas 回退。未随工程分发字体文件；其他机器可能替换字体并影响版面/像素一致性。未宣称这些字体为 OFL。
- Playwright-core 负责浏览器控制；Chrome 负责 Canvas；FFmpeg 负责编码/混音。软件及其分发各自保留许可，本工程不打包这些二进制。
- 声音为原创噪声滤波、衰减振荡与事件拟音，没有使用采样库、第三方曲目、TTS 或模型生视频。声音检查状态以证据文件为准。
