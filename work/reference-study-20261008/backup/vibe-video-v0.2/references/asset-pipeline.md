# 生图、真实素材与代码合成

## 逐层选路线

| 画面需要 | 优先路线 | 保留可控性 |
|---|---|---|
| 真实事件、论文、实物或观测证据 | 原始资料与明确可用的媒体 | 保留源文件、来源和裁切记录 |
| 精细器物、人物、有机形态、艺术背景 | 内置 imagegen 或已有优质资产 | 设定帧、姿势/光照约束、分层和透明 alpha |
| 连续剖切、复杂遮挡、绕行 | 成熟三维模型或真实摄影视频 | 尺度、相机、材质和缓存轨迹 |
| 机制、数值、光路、箭头、精确标注 | 帧驱动代码 | 参数、固定种子、可寻址状态 |

不要为证明「代码做视频」牺牲质量。也不要让生图虚构数据、公式、历史证据或产品真实界面。

## 生图资产

使用可用 `imagegen` 技能的内置工具；已授权时直接生成，无需再索要 API key。提示词写用途、主体形态、构图、视角、光源、材料和不应出现的元素。标题、图表数值与需要动画的文字留给代码。

先生成设定图并看实际输出。镜头需要前景/背景分别运动时，生成独立层；能用原生透明背景时优先 alpha，不默认绿幕。每层记录完整画布尺寸、锚点、可见区域、深度和光照。裁去透明边时保存原始左上角偏移；否则合成坐标会漂移。多个姿势锁定角色身份、比例、服饰、镜头和光照。

项目引用的生成图复制进项目素材目录，并保存提示词及实际工具输出路径。透明材质检查半透明边缘在浅/深底上是否干净。修图与重画仍用生图编辑能力；合成、格式转换、已授权裁切与遮罩是媒体管线操作。

## 网络素材

从原发布者、机构媒体库或可核实许可证的资源取材。搜索结果仅是线索，公开可浏览不等于可再发布。用户许可搜索/下载时无需逐项询问；用途受限且不符合任务时换可用素材，不默认扩大授权。

保存一个简短资产清单（JSON 或 Markdown 即可）：`id / local_path / source_page / download_url / creator_credit / reuse_basis / retrieved_at / kind / dimensions / sha256 / derivatives / used_in`。`kind` 区分真实记录、科学可视化、生成概念图和原创代码。网络受阻、不可下载或许可证不清时如实记录，不能虚构已取得素材。

保留原图/原片。派生项记录像素裁切或源时间窗、播放速度、目标帧窗与变换。不裁掉会改变语义的轴、单位、上下文或版权署名。生成概念图若容易被理解为真实证据，在画面或说明中标记示意。

## 合成与分辨率

源图尺寸要支撑镜头最大裁切和放大：目标 1920px 宽、最大放大 2 倍时，考虑至少约 3840px 的对应源区域。源分辨率不足就减少放大、换素材或重生成，不用锐化掩盖。

用一个场景坐标体系保存世界锚点；文字 HUD 留在屏幕层。远近层只给必要视差，静态照片的二维移动是编辑运镜，不称真实三维。融合检查色温、黑位、颗粒大小、阴影方向与边缘锐度，避免主体像贴在背景上。

Remotion 图片使用 `Img` 并等待加载。视频 API 必须以项目已安装版本的类型/文档确认；`trimBefore` 等参数不能只凭名称猜单位。源时间 `s` 与源帧/输出帧明确转换，变速后重新核对声音、字幕与动作窗口。最终素材本地化以便重渲；有意使用远程资源时记录外部依赖。
