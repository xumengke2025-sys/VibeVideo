## 可复查证据

- `reference-sources/github-expansion-20261011/manifest.json`：本轮归档。每个仓库`SOURCE.json`固定版本、原路径、逐文件SHA256及许可文件。
- `discovery.json`、`github-search-*.json`和`discovery/`：GitHub搜索及候选核查记录。匿名API额度不足和压缩包下载中断后使用认证CLI读取树、逐文件下载，原样Git blob SHA1核验记录于SOURCE.json。
- `verification.json`：归档文件哈希、固定树/快照完整性、入口、源码/媒体对应等工程验证。
- `media-verification.json`：新增视频元数据、完整解码和缩略图记录。
- `browser-verification.json`：目录布局、筛选和播放器工程检查；不作为完整视听审片报告。
