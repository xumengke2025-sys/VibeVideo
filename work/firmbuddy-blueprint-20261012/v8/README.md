# FirmBuddy V8 · 减持商机前置触达

52 秒，1920×1080，30 fps。入口 `index.html`；确定性绘制 `film.js`。

依据已确认的七阶段概念，重建同一张图纸上的独立代码部件：三入口、筛选传动、四排阶梯专家会场、六类资料仓、成果滑台、确认锁扣和外围反馈轨道。概念图不作为平移或切换背景使用。

开场载纸已改为“示例客户信息”。减持示例的整条链路为：客户池/股东名单→前置信号扫描→识别重点客户→专家研判→知识查证与客户分型→触达策略与话术→人工确认纳入商机中心→触达记录反馈。原扩产、资金缺口、融资提问已移除。

九业务席区仍沿用系统原分类；参与会商的个别专家为股东增减持、解禁预警、拜访策略。知识库事先装配，展示股东资料、信号规则、减持规范、触达策略、风险合规、案例档案六组资料。历史执行和市场观察为示例依据，核验主体、时效和反向条件后，示例客户分型为存量股东服务回访，示例建议为触达；其他候选可观察或暂缓。

前置信号不等于已确认减持需求；人工确认纳入跟进不代表客户具有减持意图。候选进入商机中心仍标“需求未确认”，客户明确需求后再进入正式减持服务。触达策略回答何时联系、由谁触达、怎么开场以及哪些话不能说。没有真实客户、实际扫描或个体减持概率展示，成果按需生成。

摄影采用一条绝对时间轨迹：五次 Hermite 插值，连接处共享速度、加速度为零，缩放在对数空间中进行。停机对应阅读窗口；其他过渡经长导轨和弧形支路承接。纸纹固定在世界坐标。

## 复现

在本工程根目录运行 `node server.mjs --serve`，浏览器访问 `http://127.0.0.1:8768/v8/index.html`。Node 需可导入 playwright-core，Chrome 默认使用本机已安装版本。`render.mjs` 支持环境变量 FIRMBUDDY_PLAYWRIGHT、FIRMBUDDY_CHROME、FIRMBUDDY_FFMPEG、FIRMBUDDY_FFPROBE。

正式导出：`node v8/render.mjs --mode=final --version=v8-reduction --width=1920 --fps=30`。修改源码后使用新的version。

`scene-body.js` 是主体可编辑来源；`setup.py` 使用本版film.js内的基础辅助函数重建入口，不依赖历史V5，不会恢复配音。改音乐后执行 `make_audio.py`，需要NumPy和imageio-ffmpeg；已有最终混音可直接渲染。

沿用纯音乐版，无中文配音与长段口播字幕。音乐为原创立体声电子配乐，含低音、底鼓、军鼓、镲、短音琶音与和声。乐句约143–166 BPM，按动作落点编排；阅读段减少密度，旅行段增加推进。31.2秒滑块落定、37.9秒人工确认锁扣、47.5秒拉远完成前安排短停顿，再用重拍承接结果。专家点亮及意见汇入由上行短音回应，50.4秒进入结尾和弦。

`plan.json.soundtrack` 为配乐时间来源；`audio/timing.json` 保存28项动作落点、声部事件、响度和混音哈希。音频生成不读取任何语音文件。最终mix.wav为48kHz双声道，两遍响度处理目标-15 LUFS、真峰值-1.5 dBTP；music.wav和foley.wav为母带前分轨。V7相机、路径、动作时间和音乐波形保留，内容文字与必要尺寸更新，历史版本未覆盖。

渲染保持串行。真实低清预演可传 `--width=960`，会降低全部像素缓冲。工具不控制或结束其他项目进程。
