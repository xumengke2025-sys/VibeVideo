# FirmBuddy V7 · 纯音乐机械蓝图

52 秒，1920×1080，30 fps。入口 `index.html`；确定性绘制 `film.js`。

依据已确认的七阶段概念，重建同一张图纸上的独立代码部件：三入口、筛选传动、四排阶梯专家会场、六类资料仓、成果滑台、确认锁扣和外围反馈轨道。概念图不作为平移或切换背景使用。

九业务席区沿用 FirmBuddy 系统分类；产业链洞察、财务诊断、拜访策略是参与会商的个别专家名。知识库预先装配，运行时在可见范围内检索；扩产披露仅为待核实线索。用户确认控制任务创建，实际用户记录再进入反馈。成果按需生成。

摄影采用一条绝对时间轨迹：五次 Hermite 插值，连接处共享速度、加速度为零，缩放在对数空间中进行。停机对应阅读窗口；其他过渡经长导轨和弧形支路承接。纸纹固定在世界坐标。

## 复现

在本工程根目录运行 `node server.mjs --serve`，浏览器访问 `http://127.0.0.1:8768/v7/index.html`。Node 需可导入 playwright-core，Chrome 默认使用本机已安装版本。`render.mjs` 支持环境变量 FIRMBUDDY_PLAYWRIGHT、FIRMBUDDY_CHROME、FIRMBUDDY_FFMPEG、FIRMBUDDY_FFPROBE。

正式导出：`node v7/render.mjs --mode=final --version=v7-music --width=1920 --fps=30`。修改源码后使用新的version。

`scene-body.js` 是主体可编辑来源；`setup.py` 使用本版film.js内的基础辅助函数重建入口，不依赖历史V5，不会恢复配音。改音乐后执行 `make_audio.py`，需要NumPy和imageio-ffmpeg；已有最终混音可直接渲染。

本次取消所有中文配音与长段口播字幕，保留图纸内的业务标签、问题、引用和成果。音乐为原创立体声电子配乐，含低音、底鼓、军鼓、镲、短音琶音与和声。乐句约143–166 BPM，按动作落点编排；阅读段减少密度，旅行段增加推进。31.2秒滑块落定、37.9秒确认锁扣、47.5秒拉远完成前安排短停顿，再用重拍承接结果。专家点亮及意见汇入由上行短音回应，50.4秒进入结尾和弦。

`plan.json.soundtrack` 为配乐时间来源；`audio/timing.json` 保存28项动作落点、声部事件、响度和混音哈希。音频生成不读取任何语音文件。最终mix.wav为48kHz双声道，两遍响度处理目标-15 LUFS、真峰值-1.5 dBTP；music.wav和foley.wav为母带前分轨。V6场景和相机源码逐字保留，历史版本未覆盖。

渲染保持串行。真实低清预演可传 `--width=960`，会降低全部像素缓冲。工具不控制或结束其他项目进程。
