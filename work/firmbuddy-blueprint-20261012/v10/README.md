# FirmBuddy V10 · 专业专家团与 AI 全程协作

52 秒，1920×1080 横屏，30fps；原创电子纯音乐，无中文配音。深蓝机械设计图纸，一张连续世界中的整体流水线，保留专家半圆阶梯会场和系统九业务分类。

本版开头改为通用“商机查询”，进入扫描环节明确“以减持商机为例”。承接上一版的三个重点：专业专家的知识与培养基础、AI 每一步的业务作用、明确且专业的行动状态。

专家不只有名称的席牌：专业知识装备、业务方法沉淀、培养与试炼三条供给接入专家席位，随后股东增减持、解禁预警、拜访策略专家协同研判。专业培养依据材料、方法、知识装备和试炼发布体系。

AI 全过程：理解自然语言并调用专业工具 → 解读规则扫描结果 → 汇总多专业研判 → 检索与交叉查证 → 辅助客户分型 → 生成触达策略和话术 → 根据触达记录辅助复评。确定性扫描规则负责信号求值；AI 把专业依据组织成可执行的业务建议。

多源知识库展示核心规范、监管规则、产品能力、案例经验、研究资料、补充资料六类知识装备；多层资料抽屉与抽页展示检索查证，保留原文引用和主体、时效、反向条件核验。减持前置触达为示例业务，三入口还包括业务问题答疑和客户拜访准备。

画面采用重点客户研判、触达准备、人工审核入库、客户经营跟进等业务动作。人员审核后将减持线索纳入商机中心，持续沟通需求、匹配服务、推进合作。示例客户信息为动画案例，具体跟进和入库由业务人员审核。

## 预览与导出

从源码包根目录执行 node server.mjs --serve，访问 http://127.0.0.1:8768/v10/index.html。预览播放器可拖动时间条。

正式导出：node v10/render.mjs --mode=final --version=v10-expert-ai --width=1920 --fps=30。需要 Node、playwright-core、本机 Chrome 和 FFmpeg/ffprobe；路径支持 FIRMBUDDY_PLAYWRIGHT、FIRMBUDDY_CHROME、FIRMBUDDY_FFMPEG、FIRMBUDDY_FFPROBE 环境变量。修改源码后使用新 version。

编辑 v10/scene-body.js 后执行 python v10/setup.py 重建 film.js，不会覆盖业务计划或音乐。最终音乐为 v10/audio/mix.wav，事件来源 v10/plan.json.soundtrack，分轨为 music.wav 和 foley.wav。合成音乐可运行 python v10/make_audio.py，依赖 requirements.txt。

相机和主路径保留 V9 的绝对时间轨迹与连续接合；新增知识供给接合与 12.1/12.5/12.9 秒专家点亮共享节奏点。31.2 秒滑块落定、37.9 秒审核锁扣、47.5 秒全景拉远完成与原音乐重拍对齐。知识库底部标注和扫描资料标注已与结构拉开距离。
