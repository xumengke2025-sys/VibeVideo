# 检查点 — 鲸鱼 15 秒演示片《5 厘米的噩梦》

## 需求
制作一段 15 秒演示视频介绍鲸鱼习性：诙谐、有巧思、给人震撼感。规格由制作者自主决策为 1080×1920 竖屏、24fps、15.0 秒。

## 能力边界（用户明示）
不能直接生成图片；画面必须优先使用 Canvas / SVG / Three.js / 现有工程，通过代码绘制并渲染。本片为纯 Canvas 2D 代码绘画 + playwright-core 逐帧截图 + ffmpeg 编码，零外部素材、零生成图像。
早期在收到该边界前生成的 4 张概念图（grass 场：krill/rise/mouth/glide）已封存于 `assets/generated-unused/`，未进入正片。

## 概念
从磷虾（约 6 厘米）视角拍的"深海恐怖片"：巨影升起 → 一口吞下比自身更重的水 → 滤食后"只留虾"印章收束幽默 → 拉远看到 30 米巨物的心跳（2 次/分）与歌声（最远 1600 公里）完成尺度反转。四段字幕构成尺度链：6 厘米 → 30 米 → 一口水 → 心跳 2 次/分。

## 事实与来源（sources.json，2026-10-09 核实）
- 蓝鲸体长约 30 米、几乎只吃磷虾；滤食一口可吞入比自身体重更多的水 — NOAA / Stanford 2016。
- 深潜时心率最低约 2 次/分 — Stanford 2019（PNAS）。
- 磷虾最长约 6 厘米（Euphausia superba）— BAS。
- 条件理想时鲸歌可传播约 1600 公里。
深度与速度为示意值，片尾数据落款已注明。

## 制作链
`timeline.mjs`（事件时间轴）→ `clips/whale.json`（镜头契约：4 镜头、动作驱动、9 事件、4 字幕、3 个连续转场）→ `film.js`（Canvas 绘制引擎）→ `render.mjs`（确定性逐帧渲染，360 帧）→ `score.py`（原创合成拟音 + 底噪床 + loudnorm 混流）。

## 视觉迭代（编码前静帧审）：v1 → v2 → v3
- v1 问题：整体偏暗、磷虾线稿感、鲸首存在感弱、尾鳍形状错误、喷口不可见、滤食漩涡成乱线。
- v2 修复对比度与鲸首结构；v3 重画磷虾（月牙形体、体积感、萌感眼睛）、连接尾鳍、提升口内亮度、喷口可读。
- v3 静帧通过后进入全片渲染；成片关键帧复检（含 3.4–4.2s 暗场量化：画面均值 0.079→0.025 的刻意压暗节拍，字幕始终锚定画面）。

## 声音设计与电平修整
- 9 个事件：spark drift / rumble / air / gulp / spray / stamp / thump(心搏) / moan(鲸歌) + 全片底噪床；无旁白、无音乐、无外部录音。
- 波形复检发现片头 0–2.5s（−39.6 dB）与 10.6–11.5s（−42 dB）近乎静音，手机外放等同无声 → 底噪床 +6 dB、drift 增益 0.5→1.0；修复后片头 −34.1 dB、过渡段 −36.5 dB，动态保留，峰值 −1.32 dB 无削波。

## 交付物与证据（out/final/）
- 成片 `whale.mp4`：1080×1920 / 24fps / 15.0s / 360 帧 / h264 + AAC 48kHz；6.53 MB；SHA256 `45646f6b21df175d444430095148258d56da846b31aa204398f9140cd3fb7604`。
- 响度：loudnorm I=−18（实测输出 −17.3 LUFS、真峰值 −1.5 dB、LRA 8.5）→ `sound-evidence.json`。
- 渲染确定性：6 次 seek 两两哈希相同（`render-evidence.json` seek.identical=true）；零页面错误。
- 全解码校验 + 关键帧联系表 + 音频电平（peak −3.72 / RMS −18.4 dBFS）→ `evidence/media-evidence.json`（technical_failures 空）。
- 审片记录：v1–v3 静帧目录 `out/whale/`、`out/whale-v2/`、`out/whale-v3/`；编码后 QA 帧 `out/final/qa/`。
