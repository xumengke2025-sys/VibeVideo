# 宝宝与妈妈 · 20时代坐姿互动 v12

40秒，1080×1920，24fps，二维，有意无声。妈妈低坐、婴儿近旁坐垫，面对面完成20种时代呼应互动。只在水彩场喝咖啡/奶瓶，最后碰掌。v12按最新反馈改为大头短身、圆润短肢、自然分腿的婴儿坐姿，大小感参照初版；重新标定肩腕与奶瓶两手刚体握持。

运行：`npm install` → `npm run preview`，打开 http://127.0.0.1:8768/film/index-v12.html 。`npm run render` 导出4段后自动拼接；`npm run check` 检查960帧关节与重载像素一致性。

编辑入口：film/seated-v12.js（布局、角色和20种动作）、film/chase-scenes-v9.js（复用的20时代元数据与背景）、film/environment-v9.js（环境局部运动）、PLAN-v12-seated.md（分镜）。

素材：头部复用20套透明生图，背景复用历史生成场景；新增六件互动道具见assets/interaction-v11/props.png。完整身体、固定长度手臂和部分道具由二维代码绘制，不是生成全身视频。头部从图集按透明边界和主体连通区域提取，原图只读保留。生成绸带作为参考，实际绸带用两只手的坐标绘制连续曲线。

人物和道具留完整空间，无固定桌子和桌花。时代背景有局部枝叶、布帘、水面及云运动。旧版本保留在原项目，当前包为v12可运行所需文件。

实际检查范围见qa/v12/production-review.json。工程检查不能代替正常速度全片观看；沿用已耗尽的一轮审核预算，本次未新增独立审片。短叠化可能有数帧双轮廓；身体为简化二维关节动画。
