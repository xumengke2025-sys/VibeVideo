# 宝宝与妈妈 · 35时代二维卡通 v7

成片：`out/mother-baby-35-eras-portrait-v7.mp4`。竖屏9:16，1080×1920，24fps，210秒（3分30秒），5040帧，有意无声。

妈妈喝咖啡，宝宝双手抱瓶喝奶；每个时代6秒，完整做完准备、举起、饮用、放回、停稳，再切换时代。保持小人物、大环境和温馨二维卡通。

## 本次调整

- 固定妈妈和宝宝的上臂、前臂长度；肩点随躯干定位，肘腕按可达范围求解，避免用拉长手臂补目标距离。
- 头、上身、下身用重叠刚体层做小幅跟随，避免整个人物网格拉扯轮廓。
- 新生成35款独立咖啡杯与35款松弛空手；活动手先张开，接杯后握紧，放回后松手并收回大腿。
- 校准杯底与桌面，桌面覆盖膝部；宝宝双手与奶瓶同步，饮用接触点随头部计算。
- 转场在动作落定后发生：环境24帧渐变、整个人物6帧短叠化。保留枝叶摆动、飘叶、蒸汽、环境视差与共享相机。

## 运行与编辑（Windows）

安装Node.js后在本目录执行：

```text
npm install
npm run sample
npm run action
npm run render
npm run check
```

`sample`导出首两个时代12秒；`action`导出现代6秒完整动作；`render`导出整片；`check`检查5040帧关节/接触/边界与乱序、重载像素一致性。浏览器运行依赖Remotion管理的Chrome。

入口`film/index-v7.html`，人物/合成实现`film/rig-v7.js`，动作时序`film/actions-v7.js`，杯桌接触登记`film/table-surface-v7.js`，渲染器`render-v7.mjs`。用本地HTTP服务打开HTML，点击画布播放/暂停；在浏览器调用`renderAt(秒数)`可寻址任意帧。HTML为制作预览，正式视频是MP4。

`upgrade_v7.py`会从保留的v6文件重建v7主实现/入口/渲染器；若要使用此生成脚本，请在该脚本修改人物逻辑，以免下次生成覆盖直接改动。动作时序单独维护于`actions-v7.js`。

运行素材共490项：每时代12项原分层素材与背景，加1个独立杯和1个松弛空手。生成母图、提示记录、提取登记、原桌面提取输入和提取脚本也在包内。运行不需重新生图。可选Python检查/联系表工具需要Python与Pillow；历史v4提取工具另需NumPy。`qa_v7.py full`完成视频全解码检查。
