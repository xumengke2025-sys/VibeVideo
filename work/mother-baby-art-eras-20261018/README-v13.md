# 宝宝与妈妈 · 20时代完整生图互动 v13

40秒，1080×1920，24fps，二维，有意无声。20个历史时代依次出现；母亲在右侧低坐，婴儿近邻左侧坐垫，面对面完成不同互动。

运行：`npm install` → `npm run preview`，打开 http://127.0.0.1:8768/film/index-v13.html ，点击画面播放/暂停。`npm run render` 渲染4段并自动拼接；`npm run check` 检查图集边界、画面范围和重载像素一致性。

编辑入口：film/sequences-v13.js（完整双人姿态提取、位置注册、各场姿态选择/停留和转场）、film/chase-scenes-v9.js（20时代元数据与背景）、film/environment-v9.js（局部环境运动）、PLAN-v13-generated-sequences.md（路线）。

本版用内置 image_gen 生成每时代完整母婴12姿态图集。手臂、衣服、脸和接触道具在同一张姿态中共同生成；没有头身拼装、代码人体、四肢切片、IK或人物网格拉伸。源图、布局修复图、逐套提示词及generation-brief.json在assets/sequences-v13。现代人物身份参照图也随包提供，原始家庭照片不打包。

播放为约每秒5–6幅手绘姿态、不同停留时间；文件以24fps输出，保留逐格动画的节奏，不是24幅全新动作/秒。删去图集中意外重复的伸手与递物，延长结果和放松姿态。代码只做完整双人图像的刚性平移/等比缩放，背景局部运动与时代叠化；人物换时代不重叠，以免出现多余手臂重影。

水彩场只喝一次咖啡/奶，现代场轻碰掌收尾；无固定桌子与桌花。旧版本保留在原项目，本包包含v13运行和查看证据所需文件。

实际查看范围、成片哈希和限制见qa/v13/production-review.json。工程解码和抽帧不能代替正常速度全片观看；历史一轮审核预算已结束，本次为制作方检查，没有新增独立审片。
