# 宝宝与妈妈 · 20时代亲子互动 v15

40秒、9:16、1080×1920、24fps、二维逐格动画，有意无声。20个历史时代依次出现；妈妈低坐在右，婴儿坐在近邻左侧，共享互动空间。人物沿用v14放大22%的完整双人姿态。

运行：`npm install`，然后 `npm run preview`。打开 http://127.0.0.1:8768/film/index-v15.html ，点击画面播放/暂停。`npm run render` 导出四段并自动拼接40秒MP4；`npm run check` 检查人物图集边界、画幅范围、乱序及重载像素一致性。

运行需要Node.js与兼容Chromium。首次渲染可由Remotion准备浏览器；也可通过环境变量 `CHROME_EXECUTABLE` 指定本地浏览器。源码包不包含node_modules或浏览器二进制。中文字体使用Microsoft YaHei，跨机器可替换为已安装的中文字体。

编辑入口：

- `film/sequences-v15.js`：共同生成的母婴完整姿态、刚性注册、逐格停留、构图和时间轴。
- `film/environment-stopmotion-v15.js`：每时代外景区域、完整鸟蝶姿态、云移动、太阳旋转及夜空小星点。
- `film/transitions-v15.js`：0.50秒柔边斜向擦拭；以遮罩交接两张完整场景。
- `film/chase-scenes-v9.js`：20时代元数据与背景路径。这是历史文件名，当前成片采用坐姿版本。
- `PLAN-v15-outside-life.md`：本版计划；`qa/v15/production-review.json`：实际查看范围与限制。

人物采用每时代共同生成的12姿态图集，手臂、衣服、面孔和互动道具在同一张图中共同生成。代码只做完整双人的刚性平移和等比缩放，约每秒5–6个完整手绘姿态，以24fps输出；没有代码人体、肢体切片、IK或人体网格拉伸。人物素材与原有互动未在本次重新生成。

室内墙体、家具、花盆、窗框保持原画。动态仅在实际窗外或外景开口中：古代壁画色飞燕、水墨燕、庭园蝶、近现代麻雀；像素场使用像素处理，彩绘玻璃保持固定。剪纸、像素和现代场把原画太阳及云分层，太阳缓缓转动、云向各自窗缘漂移。夜景用微弱星光。所有环境动作与人物共享逐格停留时钟，不移动整个房间。

本次通过内置image_gen生成透明小动物4姿态图集，启用鸟和蝴蝶行；猫行不用于成片。图集与提示词位于 `assets/environment-v15`。母婴图集、布局修复、提示词和generation-brief位于 `assets/sequences-v13`。现代身份参照图随包提供，原始家庭照片不打包。

本版完成制作方画面检查、外景遮罩像素约束、确定性和工程解码检查。源码已解包并在本机复用已安装依赖和Chromium运行：20时代全部加载，960输出帧的边界检查0问题，乱序/重载像素一致。未做新机器安装验证。历史AI一轮审核预算已用完，本次未新增独立审片；具体观察范围以production-review为准，不宣称逐帧完整审美验收。旧版成片和工程保留在原项目目录。
