# 0.2 流程的实际验证

2026-10-07 制作、10-08 完成检查的独立 10 秒测试片「看见不可见」，用于检验混合素材、可寻址时序和审帧流程。1920×1080、30fps，共 300 帧；这不是所有题材的默认模板，也不是 Claude 与 GPT 的对等实验。

## 哪些路线跑通了

- 真实观测影像：3840px NASA 星云图用于近景裁切、镜头运动和分层示意；保留来源与署名，真实图像没有被 AI 重画。
- 精细概念主体：内置 imagegen 生成透明金属光学装置，代码负责摆位、统一背景、准确中文和曲线时序。生成装置明确标记为概念图，未冒充真实硬件。
- 主动作：光点沿归一化 SVG 路径移动；同一影像的六个裁切层依次归位，再显示彩色。其素材来自已发布的 RGB 图，片内说明它不是原始滤镜数据重建。
- 实际 MP4 完整解码通过，300 帧全部导出；10 页接触表全部查看，重点剪口、主体细节与转场另看 1920px 大图。浏览器逐帧工具的前后帧、滑块和键盘控制实际测试通过。

## 从缺陷形成的检查项

| 发现 | 修法 | 后续检查 |
|---|---|---|
| 猜测 SVG 路径长度，光线未到达目标 | 使用 `pathLength={1}`，归一化虚线进度并计算行进点 | 看路径起点、途经与终点的实际帧，不仅检查代码 |
| 硬切后的首帧主体 opacity 为 0，画面近空 | 硬切时先建立主体，独立动画说明层 | 每个剪口看切前、首帧及其后连续状态 |
| 简单灰度擦除只体现滤镜变化 | 增加有语义的影像层归位，再揭示颜色 | 主动作应表达关系，不用装饰堆数量 |
| Remotion 精简 FFmpeg 缺少 select 过滤器 | ffprobe 读取实际时间戳，输出寻址到前一帧与目标帧之间，固定数量导出 | 非零窗口 85–95 的 11 帧与完整序列对应文件逐个字节一致 |

## 验证边界

没有完成全片实时播放和听音，没有旁白或专业配乐验收；动态检查来自连续帧。单个概念主体没有检验大角度绕行、真实机械接触、人物动作或完整长片叙事。接触表查看说明覆盖了每帧的缩略状态，不能代替每帧的高清细节检查。把这些能力写成后续需按题材验证的路线，不写成已达到的普遍能力。

本次工程和详细报告保存在 `work/skill-refinement-20261007/`；技能运行不依赖这个测试目录。对每次新片继续使用其自己的素材记录、渲染哈希和检查结果。
