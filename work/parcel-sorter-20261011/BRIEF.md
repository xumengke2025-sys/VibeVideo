# 《你的包裹，正在找路》— 2.5D 等距分拣中心

日期：2026-10-11 ｜ 画幅 1080×1920（9:16）｜ 30fps ｜ 目标时长 22s
交付方式：`delivery_mode: user_feedback`（用户选择①直接生成、由用户反馈修改）

## 观众与承诺

观众：任何网购过的人。开场让他期待的是"一个我看得懂的、藏在日常背后的系统"。
兑现这一期待的变化：一个被选中的包裹，从洪流里被单独挑出、单独改道、单独抛出。
结尾留下的含义：你收到的一个普通包裹，曾经在几秒钟里被一条机器单独对待过。

视觉承诺（可渲染的一帧 + 一个动作）：**上千个包裹在等距网格上同时流动，其中一个被点亮，你跟着它走完全程，看它脚下的带子横向转过来把它甩进属于它的那个格口。**

## 三个候选方向（事件机制互不相同）

| | A 自动扶梯《一块踏板的两分钟》 | B 交叉带分拣机《你的包裹，正在找路》 | C 盾构机《机器走过的地方，隧道就存在了》 |
|---|---|---|---|
| 一句话概念 | 你脚下的踏板在两端会"变平" | 一秒几百个包裹，每一个都被单独改道 | 隧道不是砌出来的，是机器一边走一边长出来的 |
| 关键视觉事件 | 同一块踏板连续展平成平板，另一端再复原 | 交叉带小车在行进中把包裹向侧方抛出 | 盾尾拼装机把最后一块管片合拢成环 |
| 观众体验 | 每天踩上去，从没注意过 | 以为是滑下去的，其实是带子横着甩出去的 | 一台机器同时是挖掘者、建造者和自己的脚手架 |
| 核心镜头 | 侧剖跟随一块高亮踏板，两端各停机看展平 | 等距全貌 → 跟随一个包裹 → 侧抛入格口停机 | 纵向剖切，盾尾断面多机构同时工作 |
| 事件逻辑 | 同一对象随行程改变形态（可逆循环） | 个体身份在洪流中被持续追踪（路由） | 过程留下不可逆的永久结构 |
| 最难实现处 | 前后滚轮走不同高度导轨产生的姿态变化 | 个体身份始终可追踪 + 侧抛因果可读 | 四套机构同框，信息密度过高 |
| 成本 | 中低（零件少） | 中高（物件多，但色彩动作天然丰富） | 高 |

**淘汰 A 的理由**：几何高度重复——一排一模一样的踏板，正面撞上本项目已登记过的失败模式（榫卯设定帧：规则盒体 + 重复元素 + 大面积空底），画面容易"整齐但空"。
**淘汰 C 的理由**：单镜信息密度过高（刀盘/推进/拼装/注浆四套机构），首次观看几乎必然看不懂，且成本最高。
**选择 B 的理由**：等距矩阵是分拣中心唯一正确的视角；包裹天然提供持续对象、色彩差异和连续动作；"追踪一个个体穿过系统"与项目已有的"流程巡览"型片子（污水处理）事件逻辑完全不同，不构成模板复用。

## 即使制作精致也不符合目标

要求解释"个体如何在系统中被路由"。如果最终只剩一堆包裹在流动、或只剩设备展示，没有让观众跟着一个具体包裹看懂**它凭什么去那个格口**，即为不成立。同理，若把"横向抛出"做成一段缓动位移而不显示带面真的转过来，机制就没有被解释。

## 事实边界

- 交叉带分拣机（cross-belt sorter）的真实原理：载货小车顶面是一条可左右运行的短皮带；小车行进到目标格口上方时皮带侧向运行，把包裹横向抛出落入斜槽。本片按此原理绘制。
- 典型产能（每秒数件、每小时数万件）是行业公开量级，本片不虚构具体数字，不使用未核实的宣传值。
- 本片是**简化原理示意**，不是真实物流系统的仿真，无排队论/调度算法求解；画面注明。
- 分拣格口标签使用真实中文城市名作为示意，非真实分拣计划。

## 风险窗口

- 11.3–12.6：带面肋条从静止转为侧向流动的中间态，肋条必须留在带面范围内、不穿出车身
- 13.5–14.4：包裹脱离带面的瞬间，必须显示"是带面推的"而不是"凭空飘走"——肋条流向、包裹位移方向、落点三者一致
- 15.6–16.6：拉远期间其他小车的抛出不能糊成一片

## 一处需要写准的事实

交叉带小车的**带面本身不旋转**，是整条带面朝左或朝右运行，靠摩擦把包裹推出去。
因此片中用"带面肋条纹路朝侧向流动"来表现，而不是让带面转动 90°；包裹离开后带面停住。
真实分拣机两侧都能出格（带面可双向运行），本片内圈与外圈格口都做了出格动作。

## 声音

原创合成，无声旁白。主时钟为动作驱动：接触、抛出、落定各有事件音。
节奏：低频机械底噪铺底；扫码声落在光幕穿过；侧行摩擦声落在带面启动；抛出接触音落在脱离瞬间；结尾多声部抛出后收束。
