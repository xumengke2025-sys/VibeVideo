# v12 用户反馈修订

沿用 76 秒、9:16、1080×1920、24fps，原音乐 29.5–105.5 秒节选及主要镜头切点。

1. 已定位 v11 第 24、1115 帧异常偏绿变亮，分别在 1.00、46.46 秒。切点以外的逐帧差分定位候选后实际查看，确认是输出坏帧。v12 将 Defocus 替换为多级高斯景深，保留场景深度与倾斜清晰带；完整模型的 CPU 合成出现内存分配失败后，采用 GPU 执行新的高斯合成路径。降噪设置以正式尺寸样段的稳定性与内存实测决定。逐帧颜色、亮度突变检查进入完整输出流程，异常帧隔离并单帧重渲染，编码后重复检查。
2. 城门：国王雕像旁的使节携礼物、执扇，由祭司与守卫迎接。镜头中心微调，使人物与雕像都可读。市集：小队持盾持矛巡逻，保持市民原有散点、停留和牲畜活动；仅军队有合理队形。神像前庭及庭院神庙：白衣祭司、侍祭、供奉器物；保持阶梯与通道。
3. 主大道从近城一直至城市深处、主要横街及两岸道路补足人流。中景独立微动，远景采用实体简模合批；不把远景不可辨的步态做成高成本近景模型。桥面人物按桥面及引坡实际高程摆放。
4. 商船船体用孔雀绿、靛蓝、赭红，保留旧木甲板，增加金铜色护舷、彩边方帆、缆绳、舵桨和首尾细节。每艘商船两名船员。两组纤夫与船只共用绝对时间路径，牵引绳实际连接船上系缆点和岸上肩部。

制作验证重点：先用正式尺寸确认城门使团、市场巡逻、运河船只、祭祀和全景人潮；再检查连续样段与镜头两侧。重点防止新增角色被裁切、脚离地、绳索漂移、远景人流突断。保留蓝釉、暖侧光、窄清晰带、高位俯拍与 8Hz 世界活动。

本轮为用户反馈修订，原独立审片预算不重开。实际看过的范围和未完成的听音如实登记。历史服饰与使团场景为巴比伦幻想演绎，不作为考古复原结论。
