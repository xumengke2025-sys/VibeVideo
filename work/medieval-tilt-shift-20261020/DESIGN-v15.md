# 风衣骑手游巴比伦 · v15

沿用 1080×1920、24fps、巴比伦蓝釉巨城、Dream of Babylon 和本片已有交付方式。扩为 90 秒，让同一位自行车男子完整经过城市；用户已授权重新设计和生产，不新增逐镜确认。原 v13/v14 模型、帧和音乐均保留。

视觉承诺：从地平线露出的巨城，变成一位有点调皮的旅行者亲自走过的生活空间。米色双排扣风衣、蓝围巾、深棕帽、皮靴与酒红后包保持身份；黑漆黄铜自行车有辐条、链轮、车链、挡泥板、车铃、脚踏与皮鞍。自行车为用户指定的奇幻穿越元素。

路线：南门外 → 贯穿城门的主大道 → 市集右转 → 西岸纤道内侧 → 北部横街 → 花园北侧 → 神庙南口 → 原路短退接横街 → 北向主大道。所有镜头使用一条绝对时间世界路径；不在换镜时把人搬到不同景点。骑手逐帧动作，背景沿用微缩延时节奏。

|时间|建立 → 动作 → 结果|摄影与连接|声音计划|
|---|---|---|---|
