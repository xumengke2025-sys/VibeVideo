# 滑铁卢一分钟动画计划

建议制作《滑铁卢：没能阻止的会合》：用油画卡通人物与立体地形讲清拿破仑试图分别击败两支敌军，却未能在联军形成合力前取得胜利。成片60秒、9:16竖屏、1080×1920、30fps，中文旁白与字幕。最值得记住的画面是：镜头跟随普军进入战场，随后升高，揭示法军正面仍受阻、右侧又承受压力。

面向没有战史基础的手机观众，开场提出“为什么分开打，最后却面对两路敌军”，结尾用战场上仍在协作的两军回答。即使画面精致，若只剩人物肖像、移动箭头和标题，观众看不出普军保持行动能力、进入侧翼和法军分兵的过程，也不符合本片目标。

本轮交付计划和参考，不启动动画制作。后续已选 `delivery_mode: user_feedback`，即直接生成可播放版本，由用户反馈修改。2026年10月12日版本；本文件的制作流程取代旧《完整制作计划.md》中已撤销的强制导演及多轮审核要求，旧文件保留作历史资料。

## 为什么选滑铁卢

|候选战役|一分钟的核心事件|实施难点|取舍|
|---|---|---|---|
|滑铁卢，1815|本来要分开打，最后两支敌军形成合力|两种地图尺度与侧翼关系需交代清楚|采用。项目已有油画方向、战役研究及赤壁镜头源码资料，可直接延续|
|奥斯特里茨，1805|联军离开高地，法军夺取中央后切断联系|需要准确解释诱敌、调动与地形，已有滑铁卢资产研究难以直接使用|适合之后做胜利篇；本轮不换题|
|马伦哥，1800|法军退却后，援军反击改变局势|需要区分撤退与溃败、援军与骑兵作用，人物动作较多|适合人物故事；一分钟内更易挤压机制解释|

滑铁卢内部比较三条路线：近卫军最后进攻、泥地中的消耗、没能阻止的会合。采用第三条，近卫军作为结尾兑现；湿地只建立环境，避免把失败归结为下雨。骑兵受阻安排为一次可辨认的正面攻势，不展开全部攻防。

## 六十秒分镜与旁白

以下时间是剪辑预算，总长60秒。实际录音后在总长内调整句子和停留，不通过机械加速旁白压缩理解时间。

|时间|旁白|画面建立 → 变化 → 结果|摄影与声音|
|---|---|---|---|
|0–5秒|拿破仑想分开打，为什么最后却面对两路敌军？|油画质感战略示意中三方位置可辨 → 法军沿两军间隙推进 → 两个对手仍分开|高斜俯视推向间隙；第一秒就有部队与关系，片名小字。低鼓一击后让旁白占主位|
|5–12秒|一八一五年六月，他抢在威灵顿和布吕歇尔会合前出击。|法军前锋建立 → 指向两支军队的行动依次出现 → 观众看懂分别击败的意图|伴随前锋短移，结果时停机；只保留三个阵营标签，地图标明“战役示意”|
|12–19秒|普军在利尼败退，却仍与威灵顿保持联系。|普军受压 → 有组织沿道路退却 → 队列、旗帜和联系仍在|跟随退却，不让整支军队淡出；“6月16日·利尼”短标，脚步与音乐作声音桥|
|19–29秒|十八日，威灵顿守住山脊。法军骑兵反复冲击，也没能击破步兵方阵。|明确切到新尺度的战场，山脊和守军可辨 → 骑兵逼近已建立的方阵，沿外侧转向 → 方阵仍完整|先建立地形，再降低到中景；骑兵接近处停机。蹄声短促，保持声音低于旁白；不画马匹穿过刺刀|
|29–38秒|与此同时，普军从法军右侧陆续加入，迫使拿破仑分兵。|先前普军旗帜进入东侧道路 → 前锋沿路靠近 → 法军部分队列转向右侧，正面仍在作战|本片核心镜头：先伴随普军，再升高后拉，把注意交给法军两条应对方向；后2秒保留关系供理解|
|38–45秒|法军一度威胁联军中央，却也被侧翼战斗牵制。|联军中央受压 → 法军增援被分往侧翼 → 正面机会与右侧压力同时可见|稳定宽景，中央先动、侧翼后动，避免两处同时闪烁；屏幕小标“傍晚”，不加入新人物支线|
|45–54秒|傍晚，近卫军最后的进攻被击退，法军随之溃退。|近卫军推进队列可辨 → 火力下停滞和退却 → 邻近队列陆续后撤|中景跟进，到受阻处停机，再拉开看退却扩散；短标“近卫军”；枪声后留短空隙，不虚构历史名言|
|54–60秒|他没能在两军形成合力前，赢下这场仗。|法军退路先可辨 → 队列退出 → 两支联军与原来阵位的关系保留|回到高斜视呼应开场；最后约2秒稳定、环境声收束。只回收主问题|

旁白正文共162个汉字，不含标点；按60秒计算平均2.7字/秒。八镜分别为19、23、17、27、22、19、19、16字；开场19字分配5秒，需优先实录确认。当前尚无实际配音，字数不能代替录音测时。录音后先调整句间停顿与镜头停留，必要时缩句，保留普军进入、方阵保持和退却结果的理解时间。每镜字幕最多两行，字幕按语义分句，不逐字跳动。任何美术细节都不能挤掉关键动作。

### 观众理解顺序

以下时刻是制作预算，指完整可辨认后的停留，不代表已有画面或录音。人物与战术关系先出现，再加标注。

|镜头|出现与最早可辨认|变化与结果停留|
|---|---|---|
|0–5秒|0秒三方阵位出现，1秒可辨法军位于两军之间；三个阵营短标依次出现|2–4秒推进意图可见，4–5秒留住两军仍分离的关系|
|5–12秒|5秒沿用法军旗帜，6秒可辨前锋推进方向|7–10秒向两军方向展开行动示意，10–12秒停留读懂分别击败的意图|
|12–19秒|12秒日期切到利尼，13秒可辨同一普军旗帜|14–17秒有组织退却，17–19秒仍保留队列和联络路径|
|19–29秒|19秒切到滑铁卢，21秒可辨山脊与守军；23秒方阵轮廓清楚|24–27秒骑兵逼近后沿方阵外侧转向，27–29秒停留看方阵仍在|
|29–38秒|29秒普军旗帜进入道路，30秒可辨其身份|31–34秒队列进入侧翼，34–36秒法军分兵，36–38秒保持双向压力的宽景|
|38–45秒|38秒保留上一镜战场，39秒联军中央受压可辨|40–43秒中央危机与侧翼牵制先后呈现，43–45秒保留两处关系|
|45–54秒|45秒近卫军出现，46秒可辨队列与身份短标|47–50秒推进受阻，50–52秒先局部后撤，52–54秒看退却扩散|
|54–60秒|54秒先建立法军退路，55秒看清仍在战场的两支联军|56–58秒法军退出，58–60秒稳定画面与结句共同回收开场问题|

### 普军进入战场的跟拍设计

29–38秒以 `prussian-front` 为持续主体；世界路径是东侧道路上的弯曲行军线，沿所建地形推进到法军右侧接敌区。地图关系采用北在上、东在右，远景前完成朝向归位。道路与山脊作为不移动的空间锚点，队列旗帜跟部队移动。

|时段|主体与相机|关注对象与屏幕安排|
|---|---|---|
|29–31秒|前锋进入道路，相机从其后侧斜上方伴随；偏移保持在行进方向后方，不贴旗帜旋转|先看普军旗帜，再看脚下道路；主体位于画面中下部，前方留出行进空间|
|31–34秒|队列沿道路前进，相机与主体共享推进节奏；近处草坡、道路与远处山脊产生不同视差|旗帜保持可辨，前锋不被字幕盖住；背景相对移动证明队伍真的行进|
|34–36秒|相机减缓跟随并升高后拉，逐渐把看向点交给法军阵线；同时完成地图朝向归位|普军仍留在画面右侧，先显露法军转向应对，再显露正面守军|
|36–38秒|相机到达宽景后停留，部队继续完成各自行动|上方守军、下方法军、右侧普军形成可辨关系；“分兵”由队列转向表现，标注只作补充|

地形、主体、相机位置与看向点统一从绝对时间求值；速度变化用预设缓动，避免依赖上一帧的跟随状态。镜头中的地形与部队数量均为历史关系示意，不声称按精确比例复原战场。

### 关键镜头的连续关系

1. 开场法军旗帜承接前锋行动；战略关系建立后才推进。
2. 利尼的普军旗帜与队列，在29秒再次进入；同一身份让观众看懂“退而未灭”。
3. 19秒切换战略地图与战场地形，明确日期和尺度；不把利尼画成就在滑铁卢山脊旁。
4. 29–38秒高角度结果中，北在画面上方、东在右方；法军面向北，其右侧在东。相机换位后的局部视角由道路、旗帜和山脊承接，不能悄悄反转地图方向。
5. 普军加入与法军正面攻势有重叠，用“与此同时”及仍在活动的正面明确表示；不画成所有冲锋结束后援军才突然出现。
6. 近卫军不是瞬间全员掉头：推进、受阻、少数后撤、退却扩散要有中间态。结尾不画成法军被密闭包围。

## 美术与资产

视觉方向是阴天油画战场：灰绿草坡、赭褐湿地、温灰天空，背景笔触较软，脸、帽、军旗和兵器轮廓清楚。笔触附着物体，运动中避免纹理游泳。人物有卡通轮廓，制服与武器遵循1815年资料。

法军以钴蓝、威灵顿联军以暖赭红、普军以深灰蓝辅以浅色标签进行示意编码。标签、旗形与位置共同区分阵营；近景按具体部队还原制服，不能把威灵顿的多国军队全画成红衣英军。阵营标签不是史实军旗替代品。

制作资产约分五组：分层天空与远景；山脊、道路和简化据点地形；法军、联军、普军队列；骑兵与方阵动作资产；近卫军及退却动作资产。拿破仑肖像最多作为短暂识别，不增加三位统帅轮番介绍。

人物大转身、马匹奔跑、近卫军推进采用多姿态或成熟三维资产；平面绘画只做其支持的视差和小角度运动，不沿用埃及旧片中已发现的单图拉扯与贴片漂移。地形的高低、遮挡与队列路径由代码负责；生图负责绘画形象和质感，文字、地图和战术时序由代码生成。

字幕建议从48–58px试排，左右至少72px，下方约180px留平台安全区；依实际手机预览修正。标签跟随世界锚点，在主体可辨认后出现；同一时刻主画面尽量只有一个新标注。

## 史实依据与表达边界

主要核查依据：[英国国家陆军博物馆 Battle of Waterloo](https://www.nam.ac.uk/explore/battle-waterloo)。该页的Opening moves、Retreat to Waterloo、Positions、The Prussians arrive和Defeat of the Imperial Guard支持战略目的、普军仍保持联系、山脊防御、侧翼增兵及近卫军最后进攻的叙事。旧本地waterloo-nam.html保留作来源资料。

- 主战日期为1815年6月18日，利尼为6月16日；两个日期分别标明。
- 威灵顿指挥多国联军；布吕歇尔指挥普军。普军下午陆续投入，不是最后一刻突然到场。
- 骑兵冲锋主要由内伊组织。本片不把冲锋画成拿破仑亲自率队，也不把方阵呈现为不可战胜的机械屏障。
- 联军中央确曾处境危急，不能画成法军从头到尾毫无机会；38–45秒保留这层变化。
- 近卫军失利与联军合力共同收束主线，不能宣称某一次动作单独解释全部败因。
- 不展示未核准的精确兵力、伤亡或百分比；队列数量只作示意。不使用后建的狮子丘充当1815年的战场地形。
