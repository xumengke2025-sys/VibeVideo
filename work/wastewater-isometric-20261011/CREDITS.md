# 素材与实现来源

- 场景、程序化模型、图解、字幕与动画：本任务原创。
- 音乐：本任务原创96BPM器乐编曲（Dmaj9 / Bm7 / Gmaj7 / Asus），合成拨弦、低音、铺底和打击。声音为原创合成音效，不冒充真实现场录音。无外部歌曲、录音或旁白。
- Three.js 0.169.0，MIT；本地 vendor/THREE-LICENSE 保留许可证。
- 等距模板研究：本项目 mg-styles-15 / demos/03-isometric。参考其正交投影、共享时序和逐帧寻址；未复制城市模型或原片音乐。本片不沿用原10秒横屏规格。
- 字体：Windows本机Microsoft YaHei用于栅格成片；不随工程分发字体文件。
- 科学依据：纽约市环保局公开流程页面，链接和实际读取范围见BRIEF.md。
- 渲染控制借鉴同工作区sand-journey的本地浏览器/FFmpeg入口，保留其文件不变。
