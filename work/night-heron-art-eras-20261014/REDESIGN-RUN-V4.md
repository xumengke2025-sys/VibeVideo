# 夜鹭跨时代狂奔 · 第四版重设计

2026-10-15。当前完成：完整分镜、体型设定、四张竖屏视觉设定图。新版奔跑动画尚未渲染；旧版保留在 out/film-v3/video.mp4。本设计继承 vibe-video、效果图先行规范、9:16画幅及已有连续执行授权。

同一只夜鹭向右狂奔，经过每个时代一只动物，从其脚边或低岸石上叼走一条鱼，仰头吃掉，收颈继续跑。越往后速度和剪辑节奏越快。16场共31秒，1080×1920、24fps；每场2.25秒逐步缩到1.5秒。增加的时间用于让仰头吞咽完整可辨。画面只加时代与年份，无片名和说明文字。

## 必须完整的动作

每场都出现：缩颈奔跑 → 伸颈叼鱼 → 鱼随喙离开原处 → 边跑边仰头 → 鱼头先进入口腔、尾部最后消失 → 闭喙吞咽 → 收颈继续跑。不能把鱼从喙尖直接隐藏，也不能用跨时代切换省掉吞咽。

最短场景36帧（1.5秒）的基准：
- 0–7帧：缩颈跑，认出动物及脚边鱼。
- 8–12帧：短促伸颈，躯干仍向前。
- 13帧：喙接触鱼，鱼从地面绑定到喙。
- 14–18帧：头向右上仰起，曲颈展开，脚继续轮换。
- 19–24帧：小鱼头先进入口腔，尾部最后进入；不能凭空消失。
- 25–30帧：闭喙、轻微喉部吞咽，收颈。
- 31–35帧：喙空，维持奔跑；完成后才允许遮挡换画风。

原持有动物在鱼离地后才抬/转头，再低头看空处。所有时代同样的反应语义和相位，按物种关节实现；不把整张动物图机械摇晃代替头部反应。无攻击、无追逐。

## 物种与体型

夜鹭全长以62厘米为代表建模目标；资料中的58–66厘米是鸟长，不能拿来当站立高度。本片低身奔跑的姿态高度暂以40厘米布局，属于美术模型值，需在样段中校准。每只动物按同一世界单位投影，禁止统一设置成同样的PNG宽度。

- 棕熊：成年代表，肩高目标1.05米、头体长1.65米；可有意让后躯出画，头、前爪与鱼须清楚。通过宽景容纳，不缩成猫大小。
- 猫：自然短毛类型，头体长目标45厘米，肩高25厘米；古代不用现代品种、项圈。
- 白鹈鹕：鸟长目标1.5米，站姿明显大于低跑夜鹭，长喙、喉囊、蹼足可辨；不将鸟长误作身高。
- 水獭：头体长65厘米、尾长另计40厘米，低伏姿态；不因为尾巴长而撑高或放大躯干。
- 鸬鹚：鸟长目标85厘米，站姿高于低跑夜鹭，躯干保持可信比例；不能长成巨型鸟。
- 苍鹭：长腿、长颈，与短粗夜鹭形成清晰区别。欧洲场景用苍鹭，不用美洲大蓝鹭。
- 翠鸟：鸟长16.5厘米，约为夜鹭全长的0.27倍；停在低岸石上，鱼仅4厘米。必要时同时推近两只鸟，不能单独放大翠鸟。
- 浣熊：北美场景，保留眼罩、环尾；头体与尾长分开，不安排在古埃及或古欧洲。
- 白头海雕：北美湖岸鱼食鸟，折翼站立；鱼放在脚边外侧，避免从爪中硬夺产生对抗。

所有model数值均为成年代表体型的制作目标，不是每只个体的科学测量。来源和证据边界见 research/history-run-v4.md。

## 全场统一画风

每个时代分别统一轮廓、色盘、笔触尺寸、光照、纹理、材质和动作抽帧方式，覆盖夜鹭、动物、鱼、水、岸石、植被及前景。不会用写实羽毛配黑绘背景，或只给同一组素材换滤镜。

花叔源码继续作为材质机制来源：洞穴颜料吃进岩面；黑绘黑釉剪影、陶土刻线与少量附加色；水墨宣纸、飞白、叶片和墨晕。其他时代按对应sourceScene沿用已移植机制。室内窗桌、挂画改成可横向通过的户外水岸，不照搬与剧情无关的矩形框；背景不得残留第二只动物。

历史约束：清初不使用齐白石虾母题；1985场景采用16色8位像素，不称16位；鱼为地域相容的概括淡水鱼，不随意指定鲑鱼等物种。艺术媒介的抽象处理可以改变形状语言，不能改变基本体量和可辨物种。

## 连续跑与转场

主体世界路径、摄影机和看向点共享绝对时间；夜鹭真正沿河岸移动。远景慢移、中景河岸正常通过、近景芦苇/岩石快速掠过。连续步态不在每场重启，脚着地时保持世界接触点，摆动脚再前伸，避免滑步和人类膝关节。

多关节颈部靠S形展开完成伸缩，头与上下喙独立，贴图随连续蒙皮变形，遮住接头。仰头时身体仍低身向前；不伸成白鹭或长颈鹿颈。

画风只在本场已吞完鱼、收颈后的相同步态处切换。前景遮挡提供短暂切点，遮挡前后身体、眼睛、落脚相位及向右速度衔接；禁止半秒双动物、双风格叠化。大小动物之间的镜头尺度变化提前缓和，取鱼到吞咽期间不突然变焦。只有时代年份留在上方安全区。

## 画风切换的合理性（用户补充，2026-10-15）

按年代递进组织16场，但不同地域的画风不解释为同一条艺术进化链。北宋皮影与欧洲哥特、荷兰油画与清初水墨属于跨地域并置；通过时代年份与各自清楚的美术语言定位，不虚构师承关系。

贯穿全片的是夜鹭身份、真实体型、向右的行进、连续步态和河岸空间。各时代保留自己的原生色盘、轮廓、材质、光照与空间规则；黑绘、皮影、水墨不硬套油画阴影或写实羽毛，像素场景全元素共用像素网格。画风切换时角色、原持有动物、鱼和环境同步更换，切口两侧各自完整，不能长时间混用两种媒介。

每个切口都选相邻场景共享的岸线、草茎、石面或明暗轮廓作视觉锚点，在前景遮挡处作匹配切。遮挡前必须已仰头吞完、闭喙收颈；遮挡不能代替吞咽。新旧物种各自进入/离开，不变形成彼此。转场声音沿用连续跑步节拍，不为每时代突换音乐。

|相邻画风|共同视觉锚点|切换处理|
|---|---|---|
|洞穴岩画→埃及壁画|岩石边缘与竖直芦苇|赭石轮廓转为矿物平涂和清楚勾线；不把埃及壁画画成岩壁滤镜|
|埃及壁画→希腊黑绘|岸边草茎与水平水线|矿物色退出后显示黑釉剪影、陶土刻线；禁止写实羽毛残留|
|希腊黑绘→罗马马赛克|水岸曲线与近景岸石|越过遮挡后轮廓由石嵌块组成，角色和背景采用同级嵌块尺度|
|罗马马赛克→北宋皮影|前景芦苇剪影|嵌块退出后全场改透光皮革与幕布；保持脚底接触，不混留立体阴影|
|北宋皮影→哥特手抄本|叶片与草茎的边缘轮廓|透光剪影切到平面勾线、矿物色和克制泥金；这是跨地域跳转，不暗示师承|
|哥特手抄本→文艺复兴|近景叶片与低岸石|平面装饰空间转为一致透视与柔和体积，翠鸟按小体型呈现|
|文艺复兴→17世纪明暗油画|树干或岸边阴影|延续油画材质与光向，收敛色盘并强化明暗；不全屏突降亮度遮住夜鹭|
|17世纪明暗油画→清初水墨|深色树干与岸石|穿过遮挡后整场转宣纸、干湿墨和留白，不保留西式油画羽毛与投影|
|清初水墨→印象派|芦苇与水面亮带|保留岸线及运动方向，换为分色短笔触；不把墨线硬加满彩色滤镜|
|印象派→后印象派|草叶与水流方向|共用笔触方向作为锚点，再改变色彩与笔触组织；仍保留两种画法差异|
|后印象派→立体主义|前景岩石斜面|越过岩面后全场切为有限切面结构；不将动物身体随机碎裂|
|立体主义→黑白动画|深色芦苇和角色黑冠|保持夜鹭剪影与步态，切换成黑白墨线及动画背景；不额外加入人类手套或多肢|
|黑白动画→超现实主义|岸石或树影|保留真实岸线和侧面机位，遮挡后恢复精细体积与异常空间意象；无闪白和彩色爆闪|
|超现实主义→波普|大块前景岩面|石面遮挡后改为平涂、黑轮廓与网点，环境和海雕一起换；不加漫画对白|
|波普→8位像素|垂直草茎与水平岸线|遮挡后全场量化为统一像素网格和16色；文字仍由代码准确绘制，避免平滑插值混边|

15个逐场合同保存在transitions-run-v4.json。样段需实看切口前后连续帧：脚步/眼位不跳、体型不乱、旧动物不重影、背景没有额外动物、材质没有混留、切后仍看得懂新风格。当前为设计约束，尚未以动态画面验证。

## 动画专用生图关键姿势（用户补充，2026-10-15）

将动画专用图片列为正式制作项。现有四张整体效果图只确定视觉方向，不能充当完整奔跑资产，也不能仅拆一张静态夜鹭图后机械摆动作为最终跑动。

- 奔跑关键姿势：先建立左右脚交替的蹬地、腾空、落脚、承重姿态；至少覆盖左右半周期，使用同一角色比例、朝向、镜头、缩放和地面锚点。姿势数量服从实际连续性，不将少数静帧快速切换当成流畅动画。
- 吃鱼关键姿势：缩颈、伸颈接触鱼、叼起、仰头吞咽、闭喙收颈；与奔跑状态叠合，躯干和脚继续运动。鱼头先进入口腔，尾部最后消失。
- 资产制作：使用内置生图生成/编辑关键姿势，以选定夜鹭设定和相邻关键姿势作为参考，保持身份、轮廓与比例；按动画需求分离身体、腿、头、上下喙和可连续变形的颈部，保留透明层与动作空间。新生成图片必须逐张检查肢体数量、喙/鱼方向、物种、体型、脚底锚点和对应画风。
- 连续衔接：用同一骨架、连续变形及足部接触约束连接关键姿势，落脚阶段锁定世界接触点，避免滑步、头身跳动、颈部拼接及左右肢体翻转。关键姿势不能各自随机重绘后直接切图。
- 全16时代：先验证一套共享动作，再按每时代的媒介分别重绘对应姿势与鱼、原持有动物反应。共用动作时序和尺度，不跨时代复用不符画风的羽毛或贴图。
- 先行样段：先用水墨方向做完整“奔跑→偷鱼→仰头吞下→收颈继续跑”的实际连续样段，验证体型、重心、脚底接触、颈部和吞咽成立；随后验证熊→猫、鹈鹕→水獭的体型差异及画风切口，再批量扩展其余时代。此为制作判断，沿用既有审核预算，不新增独立审片。

## 制作顺序与约束

1. 完成现在这组整体概念、动作和体型表。
2. 先补齐动画专用生图关键姿势并用水墨制作完整奔跑吃鱼样段，再完成“熊→猫”和“鹈鹕→水獭”的体型差异及相邻转场样段。低清预演如需使用须真实降低像素缓冲；正式样段1080×1920。
3. 样段查清脚不滑、颈不露接头、鱼状态闭合、头仰起可读、体型不失真、转场无重影后，再扩展16场。鱼接触/仰头/吞咽完成与拟音共用事件表，无旁白。
4. 全片输出31秒，并做文件、画幅、24fps、帧数744、时长、音轨和完整解码检查；如实登记当前版本实际看画面/听音范围。
