# 夜鹭跨时代狂奔 · v10

本版根据用户反馈修改音乐、踩点、文字和夜鹭的嚣张步态。16时代、16种被抢动物，以及岸边固定、失鱼后惊讶并低头看空地的反应保留；无追视、无回头。

- 成片：`out/film-run-v10-swagger-beats-final/video.mp4`
- 入口：`run-v10.html`；动画：`src/run-v10.js`、`src/run-v10-legs.js`、`src/run-v10-gait.mjs`
- 事件与编曲：`audio-run-v10.mjs`、`audio/events-run-v10.json`、`audio/score-run-v10.wav`
- 计划：`production-plan-run-v10.json`
- 沿用：9:16，1080×1920，48fps，31秒，双声道AAC。

## 改动

腿部完整步幅由310改为400个世界单位。摆动腿经过高抬收腿、前踢、落脚三个清楚阶段，最高抬脚约115px（原约64px），加粗腿趾。身体增加得意起伏与小幅侧向摆动；取鱼到吞咽期间收住摆动，鱼仍绑定变换后的喙部。承重脚与近岸共用绝对世界距离，动作可以乱序寻址。

配乐为原创程序合成，重新编排拨弦低音、木琴、短铜管、切分和弦、轻鼓与动作声音，和声有分段推进与结尾收束。107个落脚声音与步态共享距离时钟；抢鱼、仰头、吞咽、鱼消失及时代切换直接读取画面事件时刻。WAV峰值0.87、RMS约0.137，无PCM削波。

时代/年份从60px细楷体改为70px嵌入粗体，暖白字、细暗描边及顶部渐隐暗底；不新增片名、说明或计分。

## 实际检查范围

制作阶段查看12张腿部源关键帧及4.5秒编码后样段的48个有序动作抽帧。16场共354时刻的岸边固定、反应状态、物种唯一性和3处乱序寻址通过。数值检查显示107个落脚音相位一致、承重脚世界漂移小于4e-12px、腿长可达、16场故事声音事件时差为0。

这是主制作的画面抽查及工程验证，非新增独立审核。既有一轮审核预算已用；没有声称完整连续观看或实际听音通过。配乐实际听感由用户播放后反馈。

最终媒体与快照哈希、最终抽帧查看范围，见同版本`qa/film-run-v10-swagger-beats-final/production-check.json`与`out/film-run-v10-swagger-beats-final/evidence.json`。
