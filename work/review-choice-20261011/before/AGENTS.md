# 创意与制作交接

耗时优化已落实在skill/vibe-video/references/review-performance.md。三个用户暂停的项目从各自PERFORMANCE-HANDOFF.md续接；开始前读最新CHECKPOINT及审核包，继承当前模型/推理，不自动恢复其他聊天。按连续帧小批审片、实际覆盖记录续接，复用有效提取，不从会话图片加载日志补造验收。默认10分钟无实质审核进展时交付标明未完成的当前版本，不停止仍有效工作的进程；已知听音工具不可用时直接报告限制。暂停不计等待期限，既有修复轮数不重置。正式片仍1080×1920，低清预演须真实降低像素缓冲。
