# 看成片的验收方法

仅在用户选择 `ai_review_once` 或明确要求审核时执行；`user_feedback` 不设置本页的额外验收关卡。一个审片者对待交付版本首次审核，制作角色最多修复一次，同一审片者必要局部复核后展示；具体覆盖、听音与停止条件见 [independent-av-review.md](independent-av-review.md)。用户明确要求先看时立即展示实际版本和状态。未看不能填 observed，用户看过也不能冒充 Agent 看过。

## 三种证据分别记录

- 技术：尺寸、帧率、时长、完整解码、字体与素材加载、声音存在与峰值。现有 `video_evidence.py` 负责媒体证据。
- 视觉：构图、细节、主体识别、材质、光照、合成、文字、内容准确性。需要实际图片理解，机器数字不替代。
- 动态与听音：注意转移、接触顺序、速度、停留、镜头衔接、音画关系。静图只能说明可见状态；完整播放与连续帧检查应分别登记。

`frame_audit.py` 默认提取每一个解码帧，保留媒体时间戳，输出分页接触表、逐帧 HTML 和候选变化点。需要 Pillow；没有 Pillow 时使用已有图像工具，不将未运行的结果当成完成。`--start-frame/--end-frame` 是包含端点的源帧号，`--width` 是证据图宽度。默认审片缩图为 960px；精细主体、字幕或瑕疵再看原尺寸。接触表上的帧号可直接回查大图。

```text
python scripts/frame_audit.py out/video.mp4 --out out/audit --cuts 90,180
python scripts/frame_audit.py out/video.mp4 --out out/cut90 --start-frame 82 --end-frame 104 --width 1920
```

`--cuts` 仅声明正常硬切的帧号；变化点仍保存，供人判断。低帧差可能是阅读停留，高帧差可能是正确剪辑。脚本不自动判「太静」「高级」「不自然」。报告包含成片 SHA256；重渲后生成新报告，防止审旧版而交新版。

## 看哪些画面

短片和正式长片均按页检查所有帧，长片分批记录覆盖与待审范围。叠化、变形、快运镜、角色换姿态、插接/受力及标签变化附近应看连续大图，有疑点再扩大窗口。只有实际看完各页及必要大图，才写「全帧检查」；仅生成序列时写「全帧已导出，尚待审阅」。

每一处缺陷记录 `frame/time / visible_issue / severity / proposed_fix / rechecked_evidence`。不要写空泛分数。优先修复事实错、关键字遮挡、主体缺失、穿透与错误接触，再修构图、材质、速度与音效。来源与示意标记也是画面检查内容。

可见粗糙的典型问题：规则几何冒充真实物体；大字遮住关键动作；所有镜头都是同一排版；角色像贴纸；纹理重复、边缘白边、轮廓锯齿；复杂背景抢主体；转场中间有双影或大面积空画面；素材放大后糊；光照和阴影不相容。修复应对应问题，不通过增加装饰数量冲分。

## 判断能否交付

### 有限返工与类型化评价

评价记录适用类型、权重和实际时间码/证据：核心视觉记忆25、递进/揭示20、运动20、镜头10、构图统一10、正确性10、音画5。无音频时按95归一化为100。按类型调整：机械/科学提高正确性与因果权重，数据提高语义，抽象可把叙事分配到形态发展；写明理由，不统一爆款公式。每个维度用 `{dimension, weight, start, end, evidence, finding}` 记录实际观察，可不打分。正确性是硬底线，不能用高创意分抵消。

首次审核找最影响质量的三个问题，登记全部严重缺陷，记录优先级、类别（创意/镜头/运动/渲染）、时间窗、可见现象、影响与改法。制作角色最多修复一次，保留旧片/旧窗和改后窗，指出改善、无改善或代价。局部重渲后核对最终导出，由同一审片者做必要改动复核，不重新全面评分或自动重构。需要大幅创意重构时先展示当前版本与建议，由用户反馈推进。

`scripts/creative_review.py prepare` 调用既有提取器，产生未观察日志与逐窗证据。`check` 检查媒体SHA256、逐镜建立/动作/结果、连续帧范围与实际审阅页、维度权重及返工前后文件；旧shot_contract调用继续兼容。日志由实际看过结果的Agent填写，提取器不自动填“通过”。原片与新版都记录时间码，比较不是模型自评分。

验收结论写当前可见事实：哪些帧/镜头检查过，哪些缺陷修过，哪些路线尚未测试。一轮结束即展示当前版本；仍有严重问题则标明未通过，覆盖或听音不足则标明未完成，不自动继续返工。局部复核不能单独证明新版整片通过。剩余项取决于新创意偏好时提供具体画面和建议，由用户反馈决定。审美不以任意「8.5 分」阈值装成客观结论，单个样片不能证明能复现网上全部 Claude 案例。
