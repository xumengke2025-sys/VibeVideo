# 渲染与审核的耗时控制

遇到制作缓慢、长片审核或恢复暂停任务时使用。先区分素材生成、浏览器初始化、寻址检查、取帧、编码、解码验证、证据导出、实际观察和等待交接；模型动作间隔不能仅凭本机CPU归因网络或服务器排队。可复制 `scripts/render_phase_timer.mjs` 记录工程阶段，不修改模型配置。

先读取现有 `delivery_mode`：`user_feedback` 仅做制作与工程检查后交付；下面的审片提取、批次、合并与等待仅适用于 `ai_review_once` 或用户另行要求的审核。旧交接包的强制每版审核与两轮上限已被两种模式取代，不自动补做旧审核，也不恢复暂停项目。

## 降低重复工作

低清预演须让主画布、三维render target、叠字层和合成层实际使用较小像素缓冲，保持原逻辑坐标、画幅和摄影关系；全高清绘制后再缩图不会减少主体渲染量。正式片尺寸按用户要求。先比较代表静帧、字体位置、转场边界、乱序/新进程一致性，再扩大输出。低清预演不替代最终尺寸的细节检查。

按现有输入哈希与导出配置恢复同一版本帧；源码、素材、声音或渲染算法改变须新版本，不能按文件存在复用旧帧。保存有效素材，不反复生成。已有全帧/音轨证据与当前视频哈希一致且完整时直接复用证据目录；提取成功不计入已审覆盖。

必要的内部样段由制作角色完成，不另派审片；已完成的动作样段确实回答预演目的时可合并重复制作阶段，写明依据。AI 审核只对待交付版本启动一次，最多修复一次并必要局部复核，不用不断生成新片重置预算。

## 有限上下文的审片续接

在派工前一次备齐本地证据索引、简短brief、镜头/声音表和来源。让审片者先保存盲看理解，再自行打开后半材料，避免第二次制作方交接等待。第一段盲看记录保留；续接者或已读剧情者不得冒充全片首次观看。

默认每批150个连续帧，带相邻边界证据；可按画面复杂度调整。每批只加载本批分页图、疑点原尺寸图与简短已确认发现。图片历史开始膨胀时保存结构化结果，用紧凑索引由同一审片者续接；无法继续时记录缺口并交付，不自动启动新审片角色。使用标准子代理入口和明确角色提示，不反复尝试不可发现的自定义角色；不要自动创建聊天、切换模型或升级档位。

`scripts/review_batches.py prepare` 复用 frame_audit 的全片索引（每页30帧）或具有显式start/end的sheets索引，生成packet和每批入口。准备参数frames/duration必须来自当前成片的实际解码与完整音频时间轴元数据，不使用故事板预计值或名义帧率推算VFR时间。脚本校验当前视频与索引哈希、分页文件哈希与全片覆盖；旧索引缺少明确布局时人工核对，不猜测其他导出器的每页帧数。

同一审片者的批次报告附batch_id、真实reviewer身份、check_av_review兼容覆盖/发现；机器只合并它声明并具备有效证据的范围，保留来源与所有严重问题。音频独立覆盖，由该审片者实际检查完整音轨；没有能力时保持pending并完成可做检查，不为缺少听音另派角色。`merge` 永不自动授予pass；整片事件关系、知识、动态和完整音轨判断并入同一轮首次审核，不增加最终验收角色。旧报告保留原件，不能从工具日志补造观察记录。

```text
python scripts/review_batches.py prepare --video <current.mp4> --index <frame-audit.json> --out <new-review-packet> --frames <decoded-count> --duration <full-AV-timeline> --has-audio --repair-round <existing-0..2> --brief <brief.json>
python scripts/review_batches.py merge --packet <packet.json> --reports <actual-batch-reports...> --out <aggregate-dir> --run-started-at <UTC-ISO-time>
```

## 等待与交付边界

默认10分钟没有新增实际覆盖、理解记录或缺陷发现时，按当前记录展示可播放版本并标明未通过/审核未完成；这是可调的软交付边界，不是审核通过，不终止仍在有效工作的子代理或外部生成进程。不能通过重复轮询、改文件时间或重新派工刷新等待期限。收到晚到审核结果继续保存；未审范围仍待审。音频工具已确定不可感知时不等待计时耗尽，直接报告限制。

暂停任务不计交付超时。准备审核包不启动时钟；实际开始审核时指定run-started-at。恢复暂停须以新run-started-at明确开启等待窗口，保留已审范围与修复轮数；`merge --paused`仅记录暂停状态，不恢复任务。无需反复读取完整聊天日志，读取简短进度与覆盖缺口即可。
