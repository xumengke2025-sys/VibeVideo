完整影片工程、制作模板、只有原片的研究合集和混合素材制作工具分别标注。没有取得对应绘制源码的案例不计作完整影片工程。已有43个 Lemo 原片继续保存在 `../upstream-videos`，本轮补齐其全部风格源码并建立对应入口。

工程检查见 `../../work/github-reference-expansion-20261011/verification.json`、`media-verification.json` 与 `browser-verification.json`。保存固定源码不等于重渲验证；本轮未批量安装依赖或执行上游技能、未做完整视听审片。

保留每个仓库原许可证。歌曲、歌词、字体、影像、品牌与第三方素材可能采用不同条款；目录已说明已知边界。未明确授权的内容仅供本地研究参考。

原片保留原画幅。本项目以后新制作的影片仍按1080×1920竖屏执行。
