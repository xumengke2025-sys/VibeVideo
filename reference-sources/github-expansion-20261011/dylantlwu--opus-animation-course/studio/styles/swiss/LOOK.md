# LOOK.md · 瑞士国际主义（范例）

> 对应网站「风格专题」四风格对照的左上角，代码见 `site/docs/public/demos/style-gps.html` 的 `swiss()`。
> **优先级**：§4 护栏 > 本镜头简报 > 本文件其他条目 > 模型默认审美

## 0. 本质

- 一句话：网格上的左对齐排版，一个信号色，靠裁切和吸附运动。
- **不是**：极简风（极简可以居中、可以淡入，瑞士不行）；数据新闻（瑞士不用衬线体、不用纸纹）。
- 风格来源：风格卡 ⑩；流派名「瑞士国际主义排版 / International Typographic Style」。

## 1. 视觉层

| 维度 | 规则 |
|---|---|
| 介质与材质 | 平面印刷品；无纹理 |
| 色彩逻辑 | 纸、墨、浅灰 + **一个**信号红；红色只用于「接收机」和「答案」——观众要找的东西 |
| 色板 token | 纸 `#F1EFE9` / 墨 `#111111` / 网格 `#E2DED4` / 信号 `#E3000F` |
| 形状语言 | 直角方块；无圆角；无描边 |
| 线条 | 2px 细线（测距）、3–4px 粗线（基线、标题下划线）；端点平头；不抖动 |
| 纹理 | 无 |
| 字体 | 中文 PingFang SC 800（标题）/ 600（正文）；字号阶梯 240 / 76 / 44 px；左对齐、右侧不齐 |
| 网格 | 12 栏，栏宽 140px，左边距 120px；所有元素左边缘对齐栏线 |

## 2. 运动层

| 维度 | 规则 |
|---|---|
| 帧率策略 | 逐帧 30fps |
| 缓动 | **只有两条**：`cubic-bezier(.7,0,.2,1)`（吸附）、linear（画线） |
| 入场 | 文字从遮罩线下升起（clip-reveal）；方块纵向裁切展开；大字从左「刀切」揭示 |
| 出场 | 一条细线横切过去后消失；不淡出 |
| 永远不动的 | 纸色、网格 |
| 转场 | 允许：硬切、裁切揭示；禁止：溶解、模糊、形变弹跳 |
| 镜头语法 | 镜头不动；需要「推近」时用版面重排代替 |
| 节奏单位 | 跟 reads 走：每个 read 一个入场动作，动作时长 0.3–0.5s |
| 错开 | 同组元素间隔 300ms（比常规慢：瑞士风靠「一次一件事」） |

## 3. 声音层

- 配乐：极简电子 / 单音钢琴，节拍清晰
- 音效：每次裁切揭示配一声短促的「咔」；画线配轻微的纸面摩擦声

## 4. 护栏

**禁用清单**：
- 淡入、淡出、模糊入、交叉溶解
- 回弹、spring、过冲
- 渐变、发光、阴影、圆角
- 居中排版
- 第二个强调色

**媒介陷阱**：
- 网格只是背景装饰、元素并不对齐它 → 每个元素的左边缘必须落在栏线上
- 用了 Helvetica / Akzidenz 显得陈词滥调 → 用 PingFang / Inter / Archivo
