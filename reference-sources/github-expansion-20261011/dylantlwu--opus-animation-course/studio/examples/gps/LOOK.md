# LOOK.md · GPS 示例片（风格卡 ① 3B1B 数学风）

> **优先级**：§4 护栏 > 本镜头简报 > 本文件其他条目 > 模型默认审美

## 0. 本质

- 深色黑板上的几何对象在连续变化，信息一次只给一个。
- **不是**：霓虹科技风（不发光、不用粒子）；PPT（不用卡片飞入）。

## 1. 视觉层

| 维度 | 规则 |
|---|---|
| 色彩逻辑 | 底 `#1C1C1C`；白 `#ECECEC` 用于结构；蓝 `#58C4DD` 只给卫星和它的球面；黄 `#FFD54A` 只给「你 / 结论」；红 `#FC6255` 只给「误差」 |
| 形状语言 | 细线（2–3px）几何；圆点；无填充大色块 |
| 字体 | 中文 PingFang SC 300 / 500；变量 x y z t 用斜体衬线（Times New Roman）；字幕 40px |
| 字幕 | 底部居中，半透明黑底条；与旁白逐句同步 |

## 2. 运动层

| 维度 | 规则 |
|---|---|
| 帧率 | 逐帧 30fps |
| 缓动 | smootherstep（Manim 式平滑）为主；数值计数用 linear |
| 入场 | 线条「写出」（按长度画出）；文字从左到右揭示 |
| 出场 | 旧元素变暗到 35%；场景结束整体淡出 0.3s |
| 时间来源 | 只用 `audio/timeline.json` 的句子起止时间，代码里不写死秒数 |

## 3. 声音层

- 旁白：edge-tts `zh-CN-YunyangNeural`
- 配乐：代码合成的低音量和弦铺底（占位），人声出现时自动避让；整体响度 -14 LUFS

## 4. 护栏

- 不发光、不用粒子、不用渐变背景
- 同一时刻只出现一个新信息（reads 不重叠）
- 所有数字都要有出处（见 narration.txt 顶部的事实核查）
- 字幕不得遮挡画面信息：画面内容保持在 y < 940

## 6. 风格块

```text

线条按长度写出，旧元素变暗到 35% 再揭示新元素；smootherstep 缓动；时间只来自 timeline.json。
禁止：发光、粒子、渐变背景、同一时刻两个新信息。
```
