# STORYBOARD · GPS 为什么要 4 颗卫星（M7 示例片）

Logline: 手机靠测到卫星的距离来定位，**而且**三个距离就能锁定一个点，**但是**手机的钟不够准、所有距离都算歪了，**所以**需要第四颗卫星把「时间」也解出来。
受众与目的: 没学过大学物理的高中生；看完能用一句话解释「为什么是 4 颗」。
World: 3B1B 数学风（见 LOOK.md）——深底、蓝色卫星、黄色结论、红色只给「误差」。
Motif: **时钟**。开场是不准的、乱跳的时钟；结尾是精确、平稳走动的时钟。
Arc: 困惑（手机不知道时间？）→ 熟悉（打雷）→ 机制（距离 = 球面）→ 危机（时钟误差）→ 释然（4 个未知数）→ 回扣（时间也解出来了）。

时间全部来自 `audio/timeline.json`，下面用「第 n 句」表示（从 0 开始）。
