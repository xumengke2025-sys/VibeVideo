# M7 示例片《GPS 为什么要 4 颗卫星》旁白（每行一句；空行 = 段落停顿）
# 事实核查：
#   声速约 343 m/s → 3 秒 ≈ 1 公里
#   光速约 30 万 km/s → 1 毫秒 ≈ 300 公里
#   三个球面一般交于两点，其中一点远离地球、可排除（因此「三颗卫星 → 一个点」的说法不严谨）
#   接收机需要同时解出 x、y、z 和自身时钟误差 → 4 个未知数 → 至少 4 颗卫星

你的手机，并不知道准确的时间。
至少，对 GPS 来说远远不够准。
那它是怎么算出你在哪的？
为什么偏偏需要四颗卫星？

先想想打雷。
看到闪电，三秒后才听到雷声，
你就知道，雷在一公里外。

GPS 卫星也在不停地广播：
我在哪，现在是几点几分几秒。
信号以光速飞来，
晚到多久，就说明离得多远。

一颗卫星，说明你在一个球面上。
两颗卫星，两个球面交成一个圆。
三颗卫星，交出两个点，
其中一个在太空里，可以排除。

但问题来了：手机的钟不够准。
差千分之一秒，距离就差三百公里。
所以，时间也是一个未知数。

三维位置加上时间，一共四个未知数。
四个未知数，就需要四颗卫星。

所以 GPS 不只算出你在哪，
还顺便算出了精确的时间。
