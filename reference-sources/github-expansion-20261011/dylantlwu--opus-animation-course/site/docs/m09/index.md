## 1. 项目目标

为一个**真实产品**（你自己的项目最好）做一支 30 秒宣传片，同时交付：
- **16:9**（1920×1080）：B 站、YouTube、官网
- **9:16**（1080×1920）：抖音、视频号、小红书、Shorts

## 2. 竖版不是横版的裁切

同一份内容、同一条时间轴，两种画幅**各自排版**：

<AnimDemo src="/demos/m09-aspect.html" caption="左：16:9 左文右卡；右：9:16 自上而下堆叠，红色是平台 UI 遮挡区" :poster="4.5" />

把横版直接裁成竖版，会发生：标题被切掉一半、卡片只剩中间、按钮掉进平台的点赞栏下面。正确做法是**同一个 seek(t)，按画幅走不同的排版规则**：

```js
function layout(w, h) {
  if (w > h) return { head: { x: 140, y: 440, size: 112 }, card: { cx: 1380, cy: 540, w: 640 } };   // 横：左文右卡
  return { head: { x: 80, y: 380, size: 104 }, card: { cx: w / 2, cy: h / 2 + 120, w: w - 120 } }; // 竖：上下堆叠
}
```

一个 HTML 出两种片子——`__meta` 按参数切换尺寸：

```bash
node render/render.mjs "work/<片名>/index.html?ar=169" --clip --out=out/promo-169.mp4
node render/render.mjs "work/<片名>/index.html?ar=916" --clip --out=out/promo-916.mp4
```

### 竖屏的规则

| 规则 | 数值（经验值，以平台最新规定为准） |
|---|---|
| 安全区 | 上 150px、下 170px、左右 60px 不放关键信息（标题栏、点赞 / 评论按钮、文案会盖住） |
| 字号 | 比横屏**大**：竖屏在手机上是全屏，但画面更窄，一行字更少；正文 ≥ 40px |
| 一行字数 | 一行 ≤ 10–12 个汉字 |
| 构图 | 上中下三段：钩子在上 1/3，主体在中间，CTA 在下 1/3 但高于安全区 |
| 节奏 | 竖屏用户划走更快：第 1 秒就要有运动 |

## 3. 品牌一致性审查

宣传片和科普片最大的区别：**品牌是硬约束**。在 `LOOK.md` 里加一节「品牌」：

| 项 | 要写清楚 |
|---|---|
| 色板 | 品牌主色、辅助色的精确色值；哪个颜色只能用于 CTA |
| 字体 | 品牌字体文件（子集化后放进 `fonts/`）；没有就指定一款开源字体 |
| logo | 最小尺寸、留白、不能变形 / 加特效 / 改颜色 |
| 界面截图 | **只用真实截图**（`assets/`），截图要高清、去掉个人信息 |
| 语气 | 用「你」还是「您」？口号能不能改？ |

审片时多一个问题：**把 logo 遮住，这还像我们的片子吗？**

## 4. 项目流程

| 时间 | 做什么 | 闸门 |
|---|---|---|
| 周六上午 | 简报（M8 的四段结构）+ 收集真实素材（截图、logo、字体）+ 品牌 LOOK.md | G0 |
| 周六下午 | 分镜：标出每个事件在第几拍；**同时画出竖版的排版草图** | G1 |
| 周日 | 横、竖各 4 张 style frames；眯眼测试；竖版叠安全区检查 | G2 |
| 第二个周六 | 动画 + 配乐卡拍（M6 的 mix.py） | G3 |
| 第二个周日 | 两个画幅终版 + 新会话严审 + 发布 | G4 |

起手提示词：

```text
读 CLAUDE.md 和 work/<片名>/LOOK.md（含「品牌」一节）。
做一支 30 秒宣传片，一个 index.html 同时支持 ?ar=169 和 ?ar=916（参考 site/docs/public/demos/m09-aspect.html）：
- 同一条时间轴（120 BPM，B(n) 表示第 n 拍），两套排版规则写在 layout(w, h) 里
- 竖版所有关键信息在安全区内（上 150 / 下 170 / 左右 60），加 ?safe=1 时画出安全区
- 界面只用 assets/ 里的截图
先给 G1：分镜表 + 横竖两版每个镜头的排版草图（文字描述位置即可），等我批准。
```
