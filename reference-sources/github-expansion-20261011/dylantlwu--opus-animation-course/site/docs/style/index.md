## 先看：同一个镜头，四种风格

下面四个画面讲的是**完全相同**的内容（M3 的「GPS 为什么要 4 颗卫星」），用的是**同一张 reads 时间表**。唯一的变量是风格。

<AnimDemo src="/demos/style-gps.html" caption="四个象限同步播放。用 0.25× 和逐帧按钮看：差别主要不在颜色，而在「东西是怎么出现的」" :poster="5.5" />

逐帧看完你会发现：

| | 瑞士国际主义 | 3B1B 数学风 | 白板手绘 | 国风水墨 |
|---|---|---|---|---|
| 东西怎么出现 | 从遮罩线下**升起 / 刀切揭示**，从不淡入 | **写出来**（从左到右）；新的来了，旧的**变暗** | **一笔一笔画出来**，慢-快-慢 | **晕开**：墨滴扩散、字由淡转浓 |
| 缓动 | 只用一条 `cubic-bezier(.7,0,.2,1)`，吸附感 | 平滑 S 曲线 | 正弦（像手的速度） | 快到轻落 |
| 帧率 | 逐帧 30fps | 逐帧 | 逐帧 | **一拍二**：画面每秒只变 12 次 |
| 「距离」怎么画 | 一根细直线 | 一个**圆**（球面的截面） | 手绘虚线 | 三丝淡墨干笔 |
| 「4」怎么写 | 巨大的红色无衬线 4 | 黄色斜体衬线 4 | 红笔写 4 再画个圈 | 行书「四」+ 一枚朱印 |
| 强调色 | 一个信号红 | 黄（结论）/ 蓝（卫星）/ 绿（变量） | 3 色马克笔，**含义固定** | 只有朱印，**全片只用一次** |

**结论：风格 = 视觉 + 运动 + 护栏。** 色板只是最表面的一层。社区里做得好的人，花最多笔墨写的是「运动语法」和「禁用清单」。

## 为什么「XX 风格」这几个字不够

不给风格约束时，Opus 5.5 有一套稳定的**默认审美**：居中大字 + 渐变背景 + 所有元素一起淡入；有人发现即使删掉相关提示，深蓝底 + 琥珀色强调也会反复出现（[iArt](https://www.iart.ai/blog/ai-javascript-animation)）。

只写一个风格名（「做成苹果风」）会好很多，但会撞上两个问题：
1. **同质化**：几百人用同一个风格名，得到同一个「Opus 理解的苹果风」——社区叫它 brief contagion
2. **漂移**：长片里风格名的解释会慢慢走样，第 10 个镜头和第 1 个镜头不像同一支片子

社区里稳定有效的做法是**三件套：点名 + 特征拆解 + 参考帧**，并把它们写进一份所有镜头共用的风格文件（`LOOK.md`）。

## 风格的四层拆解框架

本专题用一个四层框架来描述任何风格。它综合自 [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)（43 种风格、每种按 11 个维度写成 STYLE.md，强烈推荐通读）、[opus-js-animations](https://github.com/klsoen/opus-js-animations) 的风格条目和 [ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase) 的动画指南。

| 层 | 维度 | 要回答的问题 | 写法要求 |
|---|---|---|---|
| **0. 本质** | 一句话 + 「不是什么」 | 这是什么媒介？最容易和哪个风格混？ | 必须写出 1–2 个**邻近风格排除**（水墨 ≠ 水彩，白板 ≠ 蓝图） |
| **1. 视觉层** | 介质与材质 | 纸？屏幕？玻璃？墨？ | 写材料，不写形容词 |
| | 色彩逻辑 | 几种色相？底色？强调色留给什么？ | **写规则，不只写色板**（「强调色全片只用于答案」） |
| | 形状语言 | 圆角几何？直角？有机？ | 写具体：圆角 20px、无描边、真等距 30° |
| | 线条 | 粗细、端点、是否抖动 | 写数值：4 级线宽、boil 12 次/秒 |
| | 纹理 | 颗粒、网点、纸纹 | 写来源：程序生成、固定种子 |
| | 字体 | 字族、字重、字距、字号阶梯 | 中英文分别写；字幕停留 ≥ max(1.8s, 语音时长 + 0.6s) |
| **2. 运动层** | 帧率策略 | 逐帧，还是一拍二（12fps）？ | **手工媒介常用一拍二，数字媒介逐帧** |
| | 缓动性格 | 用哪几条曲线？ | 写曲线本身：`cubic-bezier(.7,0,.2,1)`、spring 阻尼 |
| | 入场 / 出场 | 东西怎么出现、怎么消失？ | 最能区分风格的一项：升起？写出？晕开？刀切？ |
| | 什么永远不动 | 背景？网格？纸？ | 不动的东西决定了「稳」 |
| | 转场语法 | 硬切？形变？一镜到底？墨晕？ | 写清楚允许和禁止的 |
| | 镜头语法 | 推拉？平移？跟着笔尖走？ | 每种运动表达什么 |
| | 节奏单位 | 按 BPM？按旁白句？ | 和 M2、M6 衔接 |
| **3. 声音层** | 音色、配乐、音效 | 钢琴？合成器？毛笔沙沙声？ | 风格也包括声音 |
| **4. 护栏** | 禁用清单 | 什么绝对不能出现？ | 越具体越好：「不准淡入」「不准渐变」 |
| | 媒介陷阱 | 这个风格最容易怎么做砸？ | 例：用滤镜冒充手绘、水墨里出现彩色 |

一个立刻能用的规律：**手工媒介（水墨、剪纸、孔版、像素）普遍「角色 12fps、镜头 24fps」混用；数字媒介（瑞士、发布会、线稿、蓝图）一律逐帧。** 在 seek(t) 里实现一拍二只要一行：

```js
const on12 = (t) => Math.floor(t * 12) / 12;   // 画面元素按 12fps 变化
```
