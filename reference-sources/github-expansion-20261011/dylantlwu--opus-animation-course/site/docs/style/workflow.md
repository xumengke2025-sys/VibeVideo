# 使用方法：把风格变成 Opus 不会误解的文件

<div class="lesson-meta"><span class="dir">导演：风格决策与控制</span><span class="tech">技术：LOOK.md、token、参考逆向</span></div>

## 1. 一支片子，一份 LOOK.md

社区里稳定出好片的人，几乎都有一份**所有镜头共用的风格文件**。[@socialwithaayan](https://x.com/socialwithaayan/status/2104519430814482644) 的「五文件工作室」把它叫 `LOOK.md`，和 `CLAUDE.md`（规则）、kit（真实素材）、scenes（镜头）、clock（统一时间轴）并列；[0xMovez](https://x.com/0xMovez/status/2104216919033192746) 的课叫它 `style_guide.md`。

本课的约定：

```
studio/
├── styles/_template/LOOK.md     ← 空白模板（按四层框架）
├── styles/swiss/LOOK.md         ← 写好的范例（对应四风格对照的左上角）
└── work/<片名>/LOOK.md           ← 每支片子一份，从模板或风格卡展开
```

`studio/CLAUDE.md` 第 4 节已经写明：**LOOK.md 存在就逐条遵守；不存在就先给 2–3 个风格方案和各一张风格静帧，等你选。**

### LOOK.md 里最重要的三节

1. **护栏**（禁用清单 + 邻近风格排除）：模型最容易「好心加戏」的地方，必须明文禁止
2. **运动层**：缓动曲线、入场出场方式、帧率策略——这是风格的主体
3. **风格块**：一段固定文字，**逐字复制**进每个镜头 / 每个子任务的提示词，不允许改写

风格块是 [vox-director](https://github.com/Alisa0808/vox-director) 的做法：它的提示词分五段（风格块 / 场景 / 纯色底 / 标题 / 技术参数），其中风格块在每一拍都逐字不变——这是长片防漂移最便宜的手段。

### 冲突时听谁的

简报说「要活泼」，LOOK.md 说「不准回弹」——听谁的？社区里有人默认简报优先，结果风格被一句临时需求冲垮。**在 LOOK.md 第一行写清优先级**：

```
优先级：LOOK.md 护栏 > 本镜头简报 > LOOK.md 其他条目 > 你的默认审美
```

## 2. 把风格变成代码常量（token 化）

LOOK.md 是给人和模型读的；代码里要有**唯一的一份 token**，所有镜头都从这里取：

```js
// 风格 token：改风格只改这里
const C = { paper: '#F1EFE9', ink: '#111', signal: '#E3000F', grid: '#E2DED4' };
const FONT = { title: '800 76px "PingFang SC", sans-serif', body: '600 44px "PingFang SC", sans-serif' };
const EASE = cubicBezier(0.7, 0, 0.2, 1);   // 本片唯一的缓动
const FRAME = (t) => t;                     // 逐帧；手工媒介改成 (t) => Math.floor(t * 12) / 12
```

[video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) 更极端：镜头逻辑和风格完全分离，只暴露一个 `ACCENT` 变量，配 9 套主题。本站的[四风格对照](/style/)也是这个思路：同一份内容和 reads，四个 `draw` 函数各管一种风格；`?s=ink` 就能单独渲染其中一种：

```bash
node render/render.mjs "../site/docs/public/demos/style-gps.html?s=ink" --clip --out=out/gps-ink.mp4
```

## 3. 点名，还是描述？

社区实测：**只描述**（「干净、高级、有呼吸感」）效果最差，模型会退回默认审美；**只点名**（「苹果发布会风」）好很多，但会同质化、会漂移。最好的是三件套：

| | 作用 | 例子 |
|---|---|---|
| **点名** | 快速对齐大方向 | 「瑞士国际主义排版」「3B1B 风格」 |
| **特征拆解** | 把名字翻译成可执行的规则 | 「只用 cubic-bezier(.7,0,.2,1)；左对齐；不淡入；一个信号红」 |
| **参考帧** | 把规则锚定到像素 | `refs/01.png`：拿网格和字重，**不拿**它的配色 |

### 边界：可以点名谁

- ✅ **流派、技法、运动名**：瑞士国际主义、构成主义、浮世绘、孔版印刷、水墨、Art Deco
- ⚠️ **工作室名**（Vox、Kurzgesagt、Apple）：可以在你和 Opus 之间当**内部速记**，但要翻译成具体特征写进 LOOK.md；不要复用它们的角色、logo、字体、配乐
- ❌ **在世艺术家的名字**：不要让模型「模仿某某画家」。即使技术上做得到，这对创作者不公平，也可能带来版权和人格权争议
- ❌ **现有 IP**：游戏角色、品牌产品轮廓、受版权保护的旋律

> 以上是创作伦理与风险提示，不构成法律意见。商用项目请自行确认。

## 4. 用参考片：从「感觉像」到「数据」

### 4.1 单帧参考：说清拿什么、不拿什么

```text
参考 refs/01.png：
- 拿：网格比例、标题字重、左对齐、留白比例
- 不拿：它的配色（用 LOOK.md 的色板）、它的 logo 和文字内容
```

### 4.2 逆向一支参考片

社区里 [@notdwd](https://x.com/notdwd/status/2104684539142648062) 的观点：只把视频丢给模型不够，要把参考片**变成数据**——抽帧、找切点、量出位置 / 尺寸 / 帧数 / 回弹量。**帧和文字描述冲突时，以帧为准。**

先抽帧做印样（**最稳的方法**，每行大致对应一个镜头）：

```bash
cd ~/ops_animation/studio
# 每秒 2 帧，拼成 6×5 的印样（覆盖 15 秒）
node render/ffmpeg.mjs -i refs/ref.mp4 -vf "fps=2,scale=320:-1,tile=6x5" -frames:v 1 -update 1 out/ref/sheet.png
```

再找切点（辅助）：

```bash
# 列出切点时间
node render/ffmpeg.mjs -hide_banner -i refs/ref.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep -oE "pts_time:[0-9.]+"
# 导出每个切点的第一帧
node render/ffmpeg.mjs -i refs/ref.mp4 -vf "select='gt(scene,0.3)',scale=480:-1" -fps_mode vfr out/ref/cut-%03d.png
```

::: warning 切点阈值要按片子调
`0.3` 适合实拍。**动态图形**的背景往往一直不变，切镜时画面整体变化很小：我们用 M2 的节拍示例实测，三个剪辑点的分数只有 0.11、0.085、0.039，用 0.3 一个都抓不到，降到 0.08 也只抓到两个（第三个和每拍的脉冲 0.035 分不开）。所以动态图形以**固定间隔印样**为主，切点检测为辅。
:::

### 4.3 语法 vs 皮肤

把参考拆成两层，这是「借鉴」和「抄袭」的分界线，也是最实用的复刻方法：

| 层 | 内容 | 处理 |
|---|---|---|
| **语法** | 时序、节奏、缓动、镜头运动、转场方式、信息层级 | **保留**：这是参考片真正值得学的东西 |
| **皮肤** | 品牌色、字体、logo、文案、角色、具体图形 | **替换**成你自己的 |

### 4.4 让 Opus 从印样起草 LOOK.md

```text
读 styles/_template/LOOK.md 的结构。
看 out/ref/sheet.png 和 out/ref/cut-*.png，为 work/<片名>/ 起草 LOOK.md：
- 只提取「语法」：缓动、入场出场方式、转场、节奏、构图规则、帧率策略
- 「皮肤」一律用我的：色板 [___]，字体 [___]
- 每条规则后面标注依据（哪一张图、哪个时间点）
- 看不出来的维度写「待定」，不要编
写完停下来，等我改。
```

## 5. 风格 bake-off：先比静帧，再定风格

不要一上来就做整片。同一拍画面，用 2–4 种候选风格**各出一张静帧**，并排比较后再定（[vox-director](https://github.com/Alisa0808/vox-director) 和 [opus-js-animations](https://github.com/klsoen/opus-js-animations) 都内置了这一步）：

```text
读 CLAUDE.md。work/<片名>/STORYBOARD.md 已批准。
从风格卡片库选的候选：瑞士国际主义 / 3B1B 数学风 / 国风水墨。
用镜头 B 的关键帧（2.4s）做一次风格 bake-off：
- 同一份内容和构图，三种风格各一个 draw 函数，用 ?s= 参数切换（参考 site/docs/public/demos/style-gps.html）
- 各出一张 --still，再拼一张 --sheet 对比
- 每种风格附三行说明：它强调了内容的什么 / 风险是什么 / 适合这支片子的哪种受众
不要写其他镜头。
```

## 6. 防漂移：长片的风格一致性

| 漂移来源 | 对策 |
|---|---|
| 风格名在不同镜头里被不同地解释 | LOOK.md + **风格块逐字复用** |
| 颜色、字号在各镜头里各写一遍 | **token 常量**只有一份 |
| 子任务 / subagent 并行写不同章节，接缝不连贯 | 所有子任务共用同一份 LOOK.md 和 token 文件；章节交付时和第 1 章的静帧**并排比较** |
| 手绘抖动（boil）的随机种子互相影响 | 每个元素独立种子：`hash(元素序号 * 1000 + floor(t * 12))` |
| 长会话后模型「忘了」风格 | 分会话时在 `HANDOFF.md` 第一行写：「先读 work/<片名>/LOOK.md」 |
| 临时需求冲垮风格 | LOOK.md 第一行写优先级 |

## 7. 混合风格

可以混，但要**主从分明**，并写进 LOOK.md：

- ✅ 「水墨为主，字幕用瑞士式无衬线体」——次风格只承担一个**明确功能**（字幕可读性）
- ✅ 「3B1B 风讲原理，数据新闻风讲统计」——按**段落**切换，切换点就是章节转场
- ❌ 「水墨里来点赛博朋克霓虹」——邻近媒介互相污染，两边都不像

## 8. 空形容词替换表

| 别写 | 改成（举例） |
|---|---|
| 高级 | 「最多 3 色；60% 留白；标题字重 800、字距 -2%」 |
| 有活力 | 「元素错开 80ms 入场；outBack 过冲 8%；剪辑点卡 128 BPM 小节线」 |
| 简洁 | 「每帧只有一个焦点；不用描边、不用阴影、不用渐变」 |
| 有质感 | 「纸纹：程序生成、固定种子；网点角度 15°；错版偏移固定 2px」 |
| 电影感 | 「24fps；180° 快门运动模糊；2.39:1 遮幅；镜头缓慢推近 5%」 |
| 中国风 | 「五墨阶 + 一枚朱印；宣纸纹理；行楷标题；人物 12fps；墨晕转场」 |
