# 练习：从看懂风格到拥有风格

作业目录：`studio/exercises/style/`。四个练习难度递增，建议两个周末做完。

## 练习 1 · 拆风格（1–2 小时，不写代码）

1. 用本专题[导读](/style/)里的四风格对照，**逐帧**（⏮ ⏭ + 0.25×）观察四个象限
2. 挑风格卡片库里的 2 张卡，各找一支代表作（卡片「参考」一栏），用四层框架填表：

| 层 | 维度 | 作品 A | 作品 B |
|---|---|---|---|
| 0 | 本质 / 不是什么 | | |
| 1 | 色彩逻辑（规则，不只是色板） | | |
| 1 | 字体 | | |
| 2 | 帧率策略（逐帧 / 一拍二？怎么判断的） | | |
| 2 | 入场 / 出场 | | |
| 2 | 转场 | | |
| 4 | 你猜它的禁用清单 | | |

**检验**：拿你的表格给别人看，对方不看视频能不能说出这是哪种风格？

## 练习 2 · 换风格（2–3 小时）

同一个 GPS 镜头，做第五种风格：**Risograph 孔版印刷**（风格卡 ⑮）。

1. **你先写** `work/gps-riso/LOOK.md`（从 `styles/_template/LOOK.md` 复制）。重点写运动层和护栏
2. 再让 Opus 实现：

```text
读 CLAUDE.md 和 work/gps-riso/LOOK.md。
参考 site/docs/public/demos/style-gps.html：内容、reads 时间表、几何完全不变，
在 work/gps-riso/index.html 里只新写一个 riso 风格的 draw 函数，全屏渲染。
先出 2.4s 和 5.5s 两张静帧，对照 LOOK.md 逐条自查，然后停下等我。
```

3. 审片时只问一个问题：**它违反了 LOOK.md 的哪一条？** 违反了就改 LOOK.md 让规则更明确，而不是只在对话里纠正——下次就不会再犯

**检验**：`--verify` 通过；错版偏移在所有帧里固定不变（风格卡里的媒介陷阱）；你的 LOOK.md 里至少有一条规则是审片后才加上的。

## 练习 3 · 逆向参考（2–3 小时）

1. 找一支你喜欢的 15–30 秒动态图形（自己录屏也行），存为 `refs/ref.mp4`
2. 按[使用方法 4.2](/style/workflow#_4-2-逆向一支参考片) 抽帧做印样、找切点
3. 让 Opus 从印样起草 `LOOK.md`，**只提取语法**，皮肤换成你的
4. 你逐条核对：每条规则的「依据」是否真的在图里？标了「待定」的维度，你自己用 ⏮ ⏭ 看原片补上

**检验**：用这份 LOOK.md 做一支 10 秒的新片，和参考片的印样并排放——节奏和运动像，但内容和配色都是你的。

## 练习 4 · 写你自己的风格卡（这是留给你的）

风格卡片库里有两种风格「暂无可靠 Opus 规范」：新粗野主义、VHS 复古失真。或者——更好的选择——**为你自己的品牌 / 频道定义一种风格**。

在 `studio/exercises/style/my-style.md` 写一张完整的风格卡，按四层框架，要求：

- 「本质」一句话 + 至少 1 个邻近风格排除
- 色彩逻辑写成**规则**
- 运动层至少写清：帧率策略、≤ 2 条缓动曲线、入场方式、出场方式
- 禁用清单 ≥ 5 条，每条都具体到可以被检查
- 一段 ≤ 6 行的风格块

这张卡没有标准答案：它取决于你想让观众**感受到什么**。写完后用它做一次练习 2 的流程，看 Opus 能不能只凭你的卡做出你想要的样子。做不出来的地方，就是卡片写得还不够准的地方。
