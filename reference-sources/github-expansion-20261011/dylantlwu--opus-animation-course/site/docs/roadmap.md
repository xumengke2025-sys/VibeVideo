# 课程地图

## 这门课教什么

社区里的爆款看起来是「一句提示词出片」，拆开看几乎都是三种能力叠加：

| 能力线 | 你要掌握的 | 对应的产出物 |
|---|---|---|
| 🔧 **技术** | seek(t) 契约、缓动与动画原理、渲染管线、声音同步、Remotion、Blender bpy | 能跑、可复现、可局部重渲的代码 |
| 🎬 **导演** | 视觉层级、构图、镜头与转场语法、节奏、审片与反馈纪律 | STORYBOARD.md、静帧、审片意见 |
| ✍️ **编剧** | 钩子、ABT 结构、概念依赖图、reads、旁白写作、事实核查 | logline、节拍表、解说稿 |

**你的角色**是总导演；Opus 5.5 是一个很强、但需要被约束的「导演兼工程师」。课程的每一步都在练：怎么把你脑子里的片子，变成 Opus 不会误解的文档和规则。

## 专题 · 视频风格

[风格专题](/style/)不属于某一课，而是贯穿所有片子：风格的四层拆解框架、16 张风格卡、`LOOK.md` 写法、参考片逆向、风格 bake-off、防漂移。
**建议在 M3 之后、和 M4 同时学**（约 2 个周末）——M4 讲视觉语言的通用原理，风格专题讲怎么把它们组合成一种可控的风格。

## 周末节奏（约 2–3 个月）

每个模块一个周末，约 6 小时：

- **周六上午（2h）**：读原理 + 在本站拖动示例、逐帧观察
- **周六下午（2h）**：Opus 实操，按闸门走一遍
- **周日（2h）**：导演/编剧训练 + 作业 + 在 `studio/CLAUDE.md` 追加你本周学到的规则

M7、M9、M12 是项目周，可以拉长到两个周末。

## 每课的固定结构

1. **本课目标**：学完能做出什么
2. **原理**：配可拖动的活体示例
3. **拆爆款**：真实案例怎么做的、好在哪
4. **Opus 实操**：可复制的提示词骨架 + 预期中间产物 + 常见翻车
5. **导演 / 编剧训练**：不写代码的刻意练习
6. **作业 + 自检清单**：对应 `studio/exercises/mXX/`

## 两个仓库目录

```
    ├── render/render.mjs  seek(t) 渲染器：--clip / --sheet / --strip / --still / --verify
    ├── templates/         canvas、svg、blender 模板
    ├── styles/            LOOK.md 风格模板与范例
    ├── exercises/         每课作业
    └── work/              你的片子放这里（每支一个子目录）
```
