# 提示词骨架 & 改片口令

## 简报骨架（六部件）

复制后填空，发给在 `studio/` 里启动的 Opus：

```text
读 CLAUDE.md。在 work/[片名]/ 做一支片子。

① 目的与受众：给 [谁] 看，看完后他们能 [理解/记住/去做 什么]
② 硬约束：[时长]s，[1920×1080 / 1080×1920]，30fps
   色板：[主色 #___ 用途] [强调色 #___ 用途] [背景 #___]
   字体：PingFang SC；正文 ≥ 28px
   禁止：[渐变背景 / 同时淡入 / 编造数字 / …]
③ 结构：[BPM] BPM，共 [N] 个镜头，剪辑点在小节线；或：按 exercises/xx/script.md 的节拍表
④ 影视语言：[用术语写 2–3 个关键运动和转场]
⑤ 参考：[链接 / 截图路径 / 拉片表]
⑥ 流程：按闸门走，先给 G0 复述和 G1 分镜，等我批准再写代码。
```

## effort 档位

| 档位 | 用在 |
|---|---|
| `medium` | 改一两个具体问题、调参数 |
| `high` | 中等改动、新增一个镜头 |
| `xhigh` | **新片、分镜、大改**（社区默认） |
| `max` | 旗舰作品的关键环节；很费额度，收益有限 |

切换：`claude --model claude-opus-5-5 --effort xhigh`，或在会话中按 Claude Code 的方式切换。

## 改片口令

格式：**镜头 + 时间 + 问题 + 期望**。每轮只提 1–2 条。

| 想说的 | 别这么说 | 这么说 |
|---|---|---|
| 太快 | 「节奏不好」 | 「镜头 C 2.4s 处标题出现到切走只有 0.5s，读不完。延长到 1.2s，后面整体顺延」 |
| 太慢 | 「有点拖」 | 「开场 0–1.2s 只有背景，删掉，第一个元素在 0.2s 出现」 |
| 动作硬 | 「不够丝滑」 | 「方块进场改成 outExpo，0.5s；落点不要过冲」 |
| 没重点 | 「画面乱」 | 「镜头 B 同时出现了 4 个元素。按 reads 拆：先标题，0.8s 后图表，再 0.8s 后高亮数字」 |
| 转场生硬 | 「转场不行」 | 「B→C 改成匹配剪辑：B 结尾的圆形缩放成 C 开头的字母 O 的位置和大小」 |
| AI 味 | 「太 AI 了」 | 指出具体俗套：「去掉渐变背景，改纯色 #0e0f13；元素错开 80ms 依次进场」 |
| 只改这里 | — | 「只改镜头 C，其他镜头不要动；改完只重出镜头 C 的静帧」 |

常用中文镜头词：「这里硬切」「推近到按钮」「缓动再慢一点」「这一幕多停一会儿」「卡在第 3 小节的强拍上」。

## 让 Opus 自审

```text
打开 out/check/sheet.png，逐帧检查：
1. 每帧的视觉焦点是什么？有没有同时两个焦点？
2. 文字有没有小于 28px、被遮挡、贴边？
3. 有没有违反 CLAUDE.md 第 4 节的任何一条？
按严重程度列问题，不要列优点。打分 1–10，低于 8 分自己改完再给我。
```

更严格：**开一个新会话**，只给它 sheet.png 和 STORYBOARD.md，让它当甲方审片。
