# 审片清单

每个闸门都过一遍。**模型说「没问题」不算数**——你自己要从头看一遍、听一遍。

## G1 分镜

- [ ] logline 是一句完整的 ABT
- [ ] 每个镜头都有**事件**（不是「X 停在画面中」）
- [ ] reads 不重叠，每个 read 留足时间（短词 ≥0.6s，一行字 ≥1.2s，一张图 ≥1.5s）
- [ ] 每个转场都写明方式，包括开头和结尾
- [ ] 结尾回收了开头的母题
- [ ] 总时长和镜头时长之和一致

## G2 静帧

- [ ] 每帧只有一个视觉焦点
- [ ] 文字 ≥ 28px（1080p），不贴边、不被遮挡，在安全区内
- [ ] 色板 ≤ 4 色，用途一致
- [ ] 没有编造的数字；有数字的都标了来源
- [ ] 中文字体正确（不是方块，不是回退的宋体）

## G3 预览

- [ ] `--verify` 通过
- [ ] 开场 1 秒内有东西在动
- [ ] 没有静止超过 2 秒的画面（结论停顿除外）
- [ ] 转场处 `--strip` 无单帧跳变 / 闪烁
- [ ] 剪辑点在拍上（有配乐时）
- [ ] 全速看一遍，0.25× 再看一遍

## G4 终版

- [ ] 1920×1080（或 1080×1920），30fps，H.264，yuv420p
- [ ] 音画同步：旁白和对应画面事件的偏差 < 0.1s
- [ ] 响度约 -14 LUFS，没有爆音
- [ ] 字幕和旁白一致，断句自然
- [ ] 第一帧和最后一帧都可以当封面

## 反「AI 味」专项

| 俗套 | 替代 |
|---|---|
| 居中大字 + 渐变背景开场 | 纯色背景 + 从一个具体元素（点 / 线 / 物体）开场 |
| 所有元素同时淡入 | 按 reads 依次登场，错开 50–120ms |
| 开场静止 1 秒以上 | 0.2s 内出现第一个运动 |
| 片尾孤零零一个 logo | 让母题收束成 logo |
| 角落里装饰性标签、无意义的网格线 | 删掉，每个元素都要有信息量 |
| 手搓的假 UI | 真截图、真组件 |
| 编造的统计数字 | 有来源的数字，或定性描述 |
| 一切都在 ease-in-out | 进场 ease-out，退场 ease-in，镜头运动 ease-in-out |
