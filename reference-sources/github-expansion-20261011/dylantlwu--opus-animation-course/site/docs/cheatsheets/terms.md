# 影视 / 动效术语

和 Opus 沟通时，术语比形容词准确得多。中英都写，它都懂。

## 运动与缓动

| 中文 | 英文 | 含义 |
|---|---|---|
| 缓入 / 缓出 / 缓入缓出 | ease-in / ease-out / ease-in-out | 起步慢 / 收尾慢 / 两头慢 |
| 快到轻落 | arrive fast, land soft | ease-out 的口语说法，UI 进场首选 |
| 过冲 | overshoot | 冲过目标再回来（outBack） |
| 回落 / 稳定 | settle | 过冲后回到目标的过程 |
| 预备 | anticipation | 动作前的反向蓄力 |
| 跟随 / 拖尾 | follow-through / overlap | 主体停了，附属部分晚一点停 |
| 错开 | stagger | 一组元素依次出现，间隔 50–120ms |
| 挤压与拉伸 | squash & stretch | 运动中形变，表现弹性和速度 |
| 弹簧 | spring | 有阻尼的振荡运动 |
| 呼吸 | breathing / idle | 静止时极轻微的周期运动 |

## 转场

| 中文 | 英文 | 含义 |
|---|---|---|
| 硬切 | hard cut | 直接切换 |
| 匹配剪辑 | match cut | 前后镜头的形状 / 位置 / 动作对齐 |
| 形变 | morph | 一个形状变成另一个 |
| 擦除 / 遮罩转场 | wipe / mask transition | 用一个形状划过画面完成切换 |
| 叠化 | dissolve / crossfade | 前后画面透明度交叉（慎用，易显廉价） |
| 推入 / 拉出转场 | zoom-through | 推进某个元素内部进入下一镜 |
| J-cut / L-cut | J-cut / L-cut | 声音先于 / 晚于画面切换 |

## 镜头与构图

| 中文 | 英文 | 含义 |
|---|---|---|
| 景别：远 / 全 / 中 / 近 / 特写 | wide / full / medium / close-up / extreme close-up | 主体在画面中的大小 |
| 推 / 拉 | dolly in / out（2D 中常用 zoom） | 镜头靠近 / 远离主体 |
| 摇 | pan | 镜头水平转动（2D 中即平移） |
| 俯仰 | tilt | 镜头上下转动 |
| 环绕 | orbit | 绕主体旋转（3D） |
| 跟拍 | tracking | 镜头跟随主体移动 |
| 焦段 | focal length | 35mm 广 / 50mm 自然 / 85mm 压缩 |
| 景深 | depth of field | 主体清晰、前后虚化 |
| 三分法 | rule of thirds | 主体放在三分线交点 |
| 留白 | negative space | 有意的空白区域 |
| 安全区 | safe area | 不会被平台 UI 遮挡的区域 |
| 下三分之一字幕条 | lower third | 屏幕下方的标题 / 人名条 |

## 节奏与声音

| 中文 | 英文 | 含义 |
|---|---|---|
| 拍 / 小节 / 强拍 | beat / bar / downbeat | 4/4 拍下 1 小节 = 4 拍 |
| 每分钟拍数 | BPM | 120 BPM → 1 拍 0.5 秒 |
| 卡点 | hit / sync to beat | 动作落在拍点上 |
| 避让 | ducking | 人声出现时音乐自动压低 |
| 响度 | LUFS | 网络视频常用 -14 LUFS |

## 文字与图形

| 中文 | 英文 | 含义 |
|---|---|---|
| 动态字体排版 | kinetic typography | 文字本身作为动画主体 |
| 视觉层级 | visual hierarchy | 第一眼、第二眼看什么 |
| 视觉母题 | motif | 反复出现并在结尾回收的元素 |
| 样式帧 / 静帧 | style frame | 定风格用的关键静帧 |
| 拉片 | shot breakdown | 逐镜头分析一支片子 |

## 渲染

| 中文 | 英文 | 含义 |
|---|---|---|
| 运动模糊 | motion blur | 快速运动的拖影 |
| 快门角度 | shutter angle | 180° = 曝光半帧（电影默认） |
| 子帧 | sub-frame | 一帧内的多个采样时刻 |
| 印样 / 缩略图拼版 | contact sheet | 多帧拼一张图用于审片 |
